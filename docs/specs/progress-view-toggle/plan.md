# 진행 상황 카드 / 상단바 전환
> 방금 입력 자리를 게이지(classic 진행 상황 카드, excel 순위 그래프)와 상단바(표 한 줄) 중 유저가 골라 쓰게 한다

## 1. Context
- 배경: v2에서 방금 입력 칸(표 한 줄, "상단바")을 진행 상황 카드로 바꿨다(`docs/tasks/ui/progress-card/`). 그 뒤 기존 상단바가 낫다는 유저 피드백이 있었다. 카드 작업 때 "고르기는 안 만들고, 별로면 그때 옵션으로" 정해 두었다. classic을 먼저 만들고(Phase 1), excel에도 순위 그래프 / 상단바 전환을 둔다(Phase 2, Dec-14). 개편 뒤 카드·그래프에 대한 부정적 피드백이 많아, 스위치가 있다는 걸 공지와 함께 스위치 옆 말풍선으로 알린다(Phase 3, Dec-27)
- 외부 제약:
  - excel의 방금 입력 자리는 순위 그래프가 맡는다(`docs/specs/excel-ui/`). excel에는 classic 상단바에 해당하는 행이 없어 새로 만든다 (Dec-15)
  - 게임 규칙과 저장 형식(`useGameState`)은 바꾸지 않는다. 바뀌는 건 보여 주는 방식뿐이다
- 기존 패턴:
  - 방금 입력 칸·기록 표 계산: `src/utils/board.ts` `buildBoard` (`latest`, `history`, `view`)
  - 카드: `src/components/classic/NewMantleForm/ProgressCard.tsx`
  - classic 상단바와 스위치: `src/components/classic/NewMantleForm/TopBar.tsx`, `ProgressViewToggle.tsx`
  - 화면 설정 저장: `src/hooks/useProgressView.ts`, `src/utils/progressView.ts` (테마 `src/hooks/useUITheme.ts`와 같은 방식)
  - excel 게임 화면: `src/components/excel/NewMantleForm/index.tsx` (행 번호 계산, 결과·그래프 탭), `RankChart.tsx`, `WordTable.tsx`
  - excel 선택된 셀: `src/utils/excelSheet.ts` `latestHistoryIndex`
  - 말풍선: 입력창 `src/hooks/useInputTooltip.ts`, 로그인 `src/components/AuthButton.tsx`, 통계 `src/components/StatsLink.tsx`, 5초 자동 닫힘 `src/hooks/useAutoDismiss.ts`. classic 순서는 `src/components/classic/ClassicHome.tsx` `hideHeaderTooltip`, 규칙은 `docs/tasks/ui/input/plan.md` 2

## 2. Scope
- In:
  - (classic) 표 머리줄 # 칸의 게이지 스위치. 카드 모드는 기록 표 머리줄을 늘 보여 준다 (Dec-3, Dec-12, Dec-13)
  - (classic) 상단바 모양: 카드 전 상단바를 되살리고, 그 뒤 바뀐 표시 규칙은 지금 기준을 따른다 (Dec-1)
  - (classic) 상단바 모드의 기록 표: 방금 단어는 다음 항목이 올 때 옮긴다 (Dec-7)
  - (classic) 상단바 방금 입력 줄의 안내: 네 가지 요청 실패와 미등록 단어 (Dec-8)
  - (classic) 고른 모양 저장과 분석 (Dec-5, Dec-9)
  - (excel) 표 머리 "시도" 칸의 스위치. 켜짐 = 그래프, 꺼짐 = 상단바 (Dec-18)
  - (excel) 시트 한 행 상단바: 표 머리 → 상단바 → 기록. 안내는 classic 상단바와 같다 (Dec-15, Dec-17)
  - (excel) 상단바 모드의 기록 표와 선택된 셀 (Dec-16)
  - (excel) 끝난 뒤 상단바 모드는 결과·그래프 탭 없이 결과만 (Dec-20)
  - (excel) 초성을 모드와 상관없이 기록 표에 넣고, 방금 항목이 초성이면 그 행을 선택 (Dec-21, Dec-22)
  - (excel) classic과 따로 저장하고 분석 (Dec-19)
  - (공통) 스위치 안내 말풍선: 스위치를 눌러 본 적 없는 사람에게 테마별로 한 번, 스위치 위 왼쪽 끝에 맞춰 (Dec-27~30, Dec-35, Dec-36)
  - (공통) 말풍선은 스위치·X·본문 클릭·보인 지 5초 중 하나로 끝나고 다시 안 뜸. 저장소를 못 쓰면 안 띄움 (Dec-31, Dec-39, Dec-40)
  - (classic) 순서: 첫 방문 모달 → 입력창 말풍선 → 보기 방식 말풍선 → 헤더 말풍선 (Dec-32, Dec-33)
  - (excel) 순서: 보기 방식 말풍선 → 로그인 말풍선 (Dec-34)
- Out:
  - 말풍선 Amplitude 수집 (Dec-37)
  - 결과창이 열렸을 때나 끝난 게임에서 말풍선 숨기기 (Dec-38)
  - excel 말풍선을 엑셀 메모 모양으로 (Dec-28)
  - 상단바 모드의 기록 표 기본 줄 수를 남는 높이에 맞춰 늘리기 (Dec-6)
  - 고른 모양을 계정에 저장해 기기 간 유지 (Dec-9)
  - excel 그래프 / 상단바 자리 높이 맞추기 (Dec-23)
  - excel 그래프 목표 점의 초성 표시 변경 (Dec-22)

## 3. Plan

### Phase 1 — 게이지 스위치와 상단바 (classic)
- 범위: 기록 표 고르기에 모드 추가, 저장값 읽기·쓰기 훅, 게이지 스위치, 상단바 컴포넌트, Amplitude
- 완료 기준:
  - 처음 들어오면 카드, 스위치를 꺼서 상단바로 바꾸면 다음에 들어와도 상단바
  - 상단바 모드에서 같은 단어가 상단바와 기록 표에 동시에 보이지 않는다
  - 요청 실패·미등록 단어가 상단바 방금 입력 줄에 보인다
  - 단어가 없을 때는 전환해도 기록 표와 푸터 위치가 출렁이지 않는다 (단어가 쌓인 뒤 움직이는 건 감수, Dec-6)
  - 카드 모드 동작은 그대로다 (기존 테스트 전부 통과)
- 진행상황: [x] 완료 (2026-11-17)

### Phase 2 — 그래프 스위치와 상단바 (excel)
- 범위: 저장 훅을 테마별로, `buildBoard`에 초성 포함 옵션, 선택된 셀 계산, excel 상단바 행, 스위치, 끝난 뒤 탭 처리, Amplitude
- 완료 기준:
  - 처음 들어오면 그래프, 스위치를 꺼서 상단바로 바꾸면 다음에 들어와도 상단바. classic 저장값과 서로 영향이 없다
  - 상단바 모드에서 같은 단어가 상단바와 기록 표에 동시에 보이지 않고, 선택된 셀은 상단바 행이다
  - 요청 실패·미등록 단어·제출 중이 상단바 행에 보인다
  - 초성 힌트를 쓰면 두 모드 모두 초성이 기록 표 맨 위에 남는다
  - 상단바 모드에서 끝나면 결과·그래프 탭이 없고, 스위치를 켜면 탭이 생긴다
  - 그래프 모드 동작은 초성 행을 빼면 그대로다 (기존 테스트 전부 통과)
- 진행상황: [x] 완료 (2026-11-18, 화면 확인 통과)
  - 저장 키 `newmantle-excel-progress-view` (`chart` / `bar`), 사용자 속성 `excel_progress_view`, 이벤트는 classic과 같은 `Progress View Switched` (`view`: `chart` / `bar`) (Dec-19)

### Phase 3 — 스위치 안내 말풍선 (classic, excel)
- 범위: 말풍선 표시 여부 계산(utils), 테마별 "다 봤음" 저장 훅, 말풍선 컴포넌트, classic 순서에 끼우기(헤더 말풍선이 기다림), excel 로그인 말풍선이 기다리게
- 완료 기준:
  - 스위치를 눌러 본 적 없는 사람은 순서가 오면 말풍선을 보고, 스위치·X·본문 클릭·5초 중 하나로 끝나면 다시 들어와도 안 보인다
  - 그 테마의 보기 방식 저장값이 있으면 처음부터 안 보인다. 다른 테마에서 끝냈어도 이 테마에서는 보인다
  - 말풍선이 떠 있는 동안 헤더(classic)·로그인(excel) 말풍선은 안 보이고, 끝나면 보인다. 숨어 있는 동안은 그 5초를 세지 않는다
  - classic 신규 유저는 입력창 말풍선이 끝난 뒤(첫 제출 뒤)에 본다
  - 기존 말풍선 테스트 전부 통과
- 진행상황: [x] 완료 (2026-11-18, 화면 확인 통과)
  - "다 봤음" 저장 키 `newmantle-progress-view-tooltip-done`, `newmantle-excel-progress-view-tooltip-done` (Dec-30)
  - classic 기록 표는 머리줄에 스위치가 있을 때 감싸는 영역의 잘림을 풀어 말풍선이 보이게 한다 (`Table`의 `containerClassName`)
  - 기존 `src/app/page.test.tsx`는 보기 방식 말풍선을 이미 본 상태에서 시작한다 (순서는 새 파일에서 본다)

## 6. Glossary
- **상단바** — 카드 전에 쓰던 방금 입력 칸. 기록 표와 같은 칸(# / 단어 / 순위 / 유사도)의 표 한 줄. excel은 같은 칸(시도 / 단어 / 순위 / 유사도)의 시트 한 행 (Dec-15)
- **진행 상황 카드** — classic의 방금 입력 자리. 배너 + 가로 게이지 (`docs/tasks/ui/progress-card/`)
- **순위 그래프** — excel의 방금 입력 자리. 엑셀 꺾은선 차트 (`docs/specs/excel-ui/`)
- **게이지 스위치** — 표 머리줄의 켜기 / 끄기 스위치. 켜면 게이지(classic 진행 상황 카드, excel 순위 그래프), 끄면 상단바. classic은 # 칸, excel은 "시도" 칸
- **초성 행** — excel 기록 표 맨 위에 들어가는 초성 힌트 줄 (Dec-21)
- **보기 방식 말풍선** — 게이지 스위치가 있다는 걸 알리는 말풍선. 스위치 위에 뜬다 (Dec-27)
