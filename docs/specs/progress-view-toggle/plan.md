# 진행 상황 카드 / 상단바 전환
> 방금 입력 자리를 게이지(classic 진행 상황 카드, excel 순위 그래프)와 상단바(표 한 줄) 중 유저가 골라 쓰게 한다

## 1. Context
- 배경: v2에서 방금 입력 칸(표 한 줄, "상단바")을 진행 상황 카드로 바꿨다(`docs/tasks/ui/progress-card/`). 그 뒤 기존 상단바가 낫다는 유저 피드백이 있었다. 카드 작업 때 "고르기는 안 만들고, 별로면 그때 옵션으로" 정해 두었다. classic을 먼저 만들고(Phase 1), excel에도 순위 그래프 / 상단바 전환을 둔다(Phase 2, Dec-14)
- 외부 제약:
  - excel의 방금 입력 자리는 순위 그래프가 맡는다(`docs/specs/excel-ui/`). excel에는 classic 상단바에 해당하는 행이 없어 새로 만든다 (Dec-15)
  - 게임 규칙과 저장 형식(`useGameState`)은 바꾸지 않는다. 바뀌는 건 보여 주는 방식뿐이다
- 기존 패턴:
  - 방금 입력 칸·기록 표 계산: `src/utils/board.ts` `buildBoard` (`latest`, `history`, `view`)
  - 카드: `src/components/classic/NewMantleForm/ProgressCard.tsx`
  - classic 상단바와 스위치: `src/components/classic/NewMantleForm/TopBar.tsx`, `ProgressViewToggle.tsx`
  - 화면 설정 저장: `src/hooks/useProgressView.ts`, `src/utils/progressView.ts` (테마 `src/hooks/useUITheme.ts`와 같은 방식)
  - excel 게임 화면: `src/components/excel/NewMantleForm/index.tsx` (행 번호 계산, 결과·그래프 탭), `RankChart.tsx`, `WordTable.tsx`
  - excel 선택된 셀: `src/utils/excelSheet.ts` `latestHistoryIndex`

## 6. Glossary
- **상단바** — 카드 전에 쓰던 방금 입력 칸. 기록 표와 같은 칸(# / 단어 / 순위 / 유사도)의 표 한 줄. excel은 같은 칸(시도 / 단어 / 순위 / 유사도)의 시트 한 행 (Dec-15)
- **진행 상황 카드** — classic의 방금 입력 자리. 배너 + 가로 게이지 (`docs/tasks/ui/progress-card/`)
- **순위 그래프** — excel의 방금 입력 자리. 엑셀 꺾은선 차트 (`docs/specs/excel-ui/`)
- **게이지 스위치** — 표 머리줄의 켜기 / 끄기 스위치. 켜면 게이지(classic 진행 상황 카드, excel 순위 그래프), 끄면 상단바. classic은 # 칸, excel은 "시도" 칸
- **초성 행** — excel 기록 표 맨 위에 들어가는 초성 힌트 줄 (Dec-21)
