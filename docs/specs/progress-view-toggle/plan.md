# 진행 상황 카드 / 상단바 전환 (classic)
> classic에서 방금 입력 자리를 진행 상황 카드와 상단바(표 한 줄) 중 유저가 골라 쓰게 한다

## 1. Context
- 배경: v2에서 방금 입력 칸(표 한 줄, "상단바")을 진행 상황 카드로 바꿨다(`docs/tasks/ui/progress-card/`). 그 뒤 기존 상단바가 낫다는 유저 피드백이 있었다. 카드 작업 때 "고르기는 안 만들고, 별로면 그때 옵션으로" 정해 두었다
- 외부 제약:
  - excel 테마는 이번 범위가 아니다. excel의 방금 입력 자리는 순위 그래프가 맡는다(`docs/specs/excel-ui/`)
  - 게임 규칙과 저장 형식(`useGameState`)은 바꾸지 않는다. 바뀌는 건 보여 주는 방식뿐이다
- 기존 패턴:
  - 방금 입력 칸·기록 표 계산: `src/utils/board.ts` `buildBoard` (`latest`, `history`)
  - 카드: `src/components/classic/NewMantleForm/ProgressCard.tsx`
  - 카드 전 상단바 코드: 커밋 `75e3d60`의 `src/components/classic/NewMantleForm/WordTable.tsx` (스쿼시 머지로 브랜치에서 빠짐)
  - 화면 설정 저장: `src/hooks/useUITheme.ts` (localStorage + Amplitude 사용자 속성 + 전환 이벤트)

## 2. Scope
- In:
  - 표 머리줄 # 칸의 게이지 스위치. 카드 모드는 기록 표 머리줄을 늘 보여 준다 (Dec-3, Dec-12, Dec-13)
  - 상단바 모양: 카드 전 상단바를 되살리고, 그 뒤 바뀐 표시 규칙은 지금 기준을 따른다 (Dec-1)
  - 상단바 모드의 기록 표: 방금 단어는 다음 항목이 올 때 옮긴다 (Dec-7)
  - 상단바 방금 입력 줄의 안내: 네 가지 요청 실패와 미등록 단어 (Dec-8)
  - 고른 모양 저장과 분석 (Dec-5, Dec-9)
- Out:
  - excel 테마 (Dec-2)
  - 상단바 모드의 기록 표 기본 줄 수를 남는 높이에 맞춰 늘리기 (Dec-6)
  - 고른 모양을 계정에 저장해 기기 간 유지 (Dec-9)

## 6. Glossary
- **상단바** — 카드 전에 쓰던 방금 입력 칸. 기록 표와 같은 칸(# / 단어 / 순위 / 유사도)의 표 한 줄
- **진행 상황 카드** — v2의 방금 입력 자리. 배너 + 가로 게이지 (`docs/tasks/ui/progress-card/`)
- **게이지 스위치** — 표 머리줄 # 칸의 켜기 / 끄기 스위치. 켜면 진행 상황 카드, 끄면 상단바
