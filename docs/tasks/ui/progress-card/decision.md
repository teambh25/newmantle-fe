# 진행 상황 카드: 결정 기록

## 시작 (2026-11-14, grill-me)

출발점: `word-list/rank-track.md` 5의 후보 "결과 카드 + 가로 게이지". 순위 트랙을 메인에서 뺀 뒤(요약이라서), 단어마다 위치를 보여 줄 방법으로 남은 안.

- 이름 "진행 상황 카드" (사용자): "결과 카드"는 정답 때 뜨는 결과창과 헷갈림
- 작업 순서 (사용자, 추천안): `feat/ui`에서 설계·구현. 정답 순간 연출만 결과창 작업과 합칠 때 맞춤 (3단계). 후보는 결과창이 합쳐진 뒤 구현 / 결과창 먼저. 카드 대부분은 진행 중 화면이라 결과창과 상관없음
- 방금 칸을 대체 (사용자, 추천안): 표 / 카드를 고르는 옵션은 안 만듦. 바뀌는 건 방금 칸 한 줄뿐이고, 고르게 하면 방금 칸의 모든 경우를 두 모양으로 맞춰야 함. 고르기는 테마 선택이 이미 맡음. 별로면 되돌리거나 그때 옵션으로
- 말풍선 내용 (사용자): 이름표("순위", "유사도") 없이 단위만. 번호는 단어 앞 `#12 사과`
  - 몇 번째 입력인지 따로 세는 자리는 만들지 않음 (2026-11-13 정함, `word-list/decision.md`). 번호는 계속 보여야 해서 말풍선에
- 게이지 눈금 (사용자, 추천안): 순위 트랙 계산(`trackPosition`)을 가로로. 후보는 순위를 고르게 (1–100위가 10%에 몰려 막판 갱신이 안 보임), 유사도로 (날마다 1위 유사도가 달라 정답 앞이 크게 빔)
- 게이지 그림 (추천안 + 사용자 수정): 바탕 회색 + 경계 금, 최고 순위까지 파랑 채움, 이번 단어 검은 표시. 단계별 색 칠하기는 알록달록해 채움이 덜 보여서 안 함. 표시 없이 채움만은 최고보다 못한 단어의 위치를 못 보여 줘서 안 함
  - 이번 단어 정보는 카드 윗줄 대신 표시 위 말풍선 (사용자)
  - 정답 자리는 동그라미 대신 폭죽 (사용자)
  - 숫자 눈금은 화면 보고 (사용자)
- 경우별 표시 (사용자): 순위 밖은 맨 왼쪽, 힌트는 번호 대신 전구, 없는 단어는 `단어 ✕`로 짧게, 실패는 경고 아이콘, 초성은 게이지 표시 없음, 정답은 폭죽 위에 정답
  - 포기: 사용자 후보는 방전 표시 / ✕ / 해골. 회색 ✕로 (추천): 해골은 놀리는 느낌, 방전은 연출이 하나 늘어 2단계에서
  - 처음: 폭죽을 채워 달라거나 터뜨려 달라는 느낌의 안내 (사용자). 은유(끈 / 도화선)는 컨셉이 바뀌는 일이라 1단계는 프로토타입으로 보고 2단계에서 정함
- 단계 나누기 (사용자, 추천안): 정적 프로토타입 → 컨셉 + 연출 → 정답 순간. 컨셉이 바뀌어도 위치 계산·말풍선·경우별 표시는 남아서 먼저 만들어도 버리는 게 적음
- 게임이 끝난 뒤 (사용자, 추천안): 폭죽·✕ 상태 유지, 폭죽 위 정답은 다음 단어를 내면 사라짐, 말풍선·채움은 계속 움직임 (채움 끝 = 기록 표 1등). 끝난 순간 얼리는 안은 계속 플레이 때 방금 단어 위치를 볼 곳이 없어져서 안 함
- 카드 겉모양 (추천안, 사용자 피드백은 나중에): 옅은 테두리 + 둥근 모서리, 그림자 없음, 높이 고정. 머리줄은 기록 표로. 테두리 없이 게이지만 두는 안은 말풍선이 떠다니는 영역의 경계가 안 보여서
- 문서 자리 (사용자, 추천안): `word-list/`에 잇지 않고 새 폴더. 테스트 ID `PC`

## 사용자 확인 없이 정한 것 (1단계)

- 접근성: 카드 = 이름 "방금 입력" 영역, 말풍선 = 상태(`status`), 게이지 = 미터(`meter`, 값은 최고 순위 위치), 정답 자리 = 상태마다 이름 다른 이미지 (`plan.md` 4). 이름 "방금 입력"을 그대로 써서 기존 테스트가 표 대신 영역을 찾게만 바꿈
- 화면 테스트는 경우별로 무엇이 보이는지와 미터 값이 오르는지/그대로인지만 본다. 위치 계산은 RT-1(로직)이 이미 봄
- 다시 낸 단어는 번호 대신 반복 아이콘 (지금 방금 칸과 같게)
- 정답 말풍선에 번호를 붙임 (`#15 사랑`). 지금 방금 칸에서도 정답 줄은 시도 번호. 포기는 번호 없이 정답만
- 말풍선 위치는 측정 없이 CSS로: 말풍선 몸통을 `left: p%` + `translateX(-p%)`로 두고 꼬리를 몸통 안 `left: p%`에. 양 끝에서도 몸통이 카드 안에 남고, 가운데 쪽에서는 꼬리가 몸통 가운데에 가까움
- 순위 밖 표시는 게이지 맨 왼쪽(위치 0). `trackPosition(-1)`(순위 밖 칸 가운데)이 아니라 사용자 말대로 끝에
- 말풍선의 순위·유사도 글씨는 기록 표와 같은 단계 색 (`TIER_TEXT`). 같은 단어가 다음에 기록 표로 내려가도 색이 같게
- 처음 안내 문구는 임시로 넣음 (`ProgressCard.tsx`에서 고침)
- 다시 잰 표 자리 최소 높이 454px (카드 86px + 머리줄이 기록 표로)
