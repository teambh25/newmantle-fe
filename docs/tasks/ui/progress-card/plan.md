# 진행 상황 카드 (classic)

입력창 아래, 기록 표 위. 방금 입력 칸(표 한 줄)을 **카드 + 가로 게이지**로 바꿔, 단어를 낼 때마다 그 단어가 정답까지 어디쯤인지와 지금까지의 최고 순위를 보여 준다. 내력은 `decision.md`. 출발점은 `word-list/rank-track.md` 5의 후보.

- 이름: **진행 상황 카드**. 정답을 맞혔을 때 뜨는 **결과창**과는 다른 것
- 방금 칸을 **대체**한다 (표 / 카드 고르기 없음). 아래 기록 표는 그대로. excel 테마는 그대로
- 목표: 색 없이도 "점점 정답에 가까워지고 있다"가 읽히게

## 단계

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1. 정적 프로토타입 | 카드 모양, 게이지 위치·채움·이번 단어 표시, 말풍선, 경우별 표시, 폭죽/✕ 아이콘, 표 자리 최소 높이. 연출 없음 | [~] 구현 완료, 사용자 화면 확인 대기 (2026-11-14) |
| 2. 컨셉 + 연출 | 1단계를 보고 게이지 은유를 정함 (폭죽 끈 당기기 / 대포 도화선 / 차오르는 막대). 최고 순위 갱신 때 빗금 → 반짝 → 채움 | [ ] 대기 |
| 3. 정답 순간 | 결과창 작업(`feat/result-answer`)과 합칠 때, 폭죽 터짐을 꽃가루·결과창 여는 지연(700ms)과 맞춤 | [ ] 대기 |

## 1. 카드 구조

```
┌──────────────────────────────────────┐  ← 옅은 회색 테두리, 둥근 모서리, 흰 배경
│            ┌──────────────────────┐  │
│            │ #12 사과  87위 72.15점 │  │  말풍선 줄 (늘 자리 확보)
│            └──────────▽───────────┘  │
│ ├───┼────┼██████████▲██┼─────┤  🎉   │  게이지 줄
└──────────────────────────────────────┘
   #      단어          순위    유사도      ← 머리줄은 기록 표로 (소제목 없음)
   3      과일           45위   51.20
```

- 틀: 옅은 회색 테두리 + 둥근 모서리. 그림자·배경색 없음 (아래 표가 선만으로 된 클래식이라 가볍게)
- **높이 고정**: 말풍선이 없는 경우(처음 등)에도 말풍선 줄 자리를 비워 둔다. 경우가 바뀌어도 아래 표가 출렁이지 않게
- 폭: 기록 표와 같은 폭
- 머리줄(# / 단어 / 순위 / 유사도)은 기록 표 맨 위로. 기록 표가 없으면(단어 없음) 머리줄도 없음
- 기록 표는 방금 단어까지 모든 단어를 순위순으로 담는다 (`word-list/plan.md` 1·5, 2026-11-16). 카드의 방금 단어가 표에도 보임

## 2. 게이지

- 왼쪽 끝 = 순위 밖, 오른쪽 끝 = 정답(폭죽). 위치는 순위 트랙 계산을 가로로 쓴다 (`rankTrack.ts` `trackPosition`)
  - 순위 단계마다 칸을 나누고 정답 쪽 칸일수록 넓게 (비율은 `word-list/rank-track.md` 6). 칸 안에서는 순위마다 같은 간격
  - 칸 비율은 화면에서 보고 조정
- 바탕: 옅은 회색 막대. 단계 경계만 옅은 세로 금. **단계별 색은 칠하지 않음**
- 채움: 왼쪽 끝부터 **지금까지의 최고 순위** 자리까지 파랑 한 색. 맞히면 막대 끝까지 (그 뒤 단어를 내도 그대로). 포기는 최고 순위까지 (2026-11-16)
  - 최고 순위 = 저장된 모든 순위 있는 단어(입력·힌트, 게임이 끝난 뒤 낸 단어 포함) 중 가장 작은 순위. 늘 기록 표 1등(또는 방금 칸 단어)과 같음
  - 순위 밖 단어만 있으면 채움 없음
- 이번 단어 표시: 핀 모양 (막대 위 ▼ + 막대를 관통하는 흰 테두리 검은 바늘). 최고보다 못한 단어면 채움 안쪽, 새 최고면 채움 끝
  - 순위 밖 단어는 게이지 맨 왼쪽 끝
- 정답 자리: 오른쪽 끝에 폭죽 아이콘. 맞히기 전 회색, 맞히면 진하게, 포기하면 회색 ✕
- **숫자 눈금**: 경계 금 아래에 경계 순위를 `위`와 함께 (`999위` `300위` `100위` `50위` `20위`, 경계 오른쪽 칸이 시작하는 순위). 사용자가 순위라는 걸 알게 "위"를 붙임 (2026-11-15)
- **지난 기록 말풍선**: 눈금 아래 한 줄. 최고 기록을 깬 단어(힌트 포함, 순위 밖·초성·정답 제외, 끝난 뒤 단어 포함)를 그 순위 자리에 작은 말풍선으로, 꼬리는 위로 자기 자리를 가리킴 (2026-11-15)
  - 방금 낸 **새** 단어는 배너와 ▼가 보여 주므로 뺌. 이미 낸 단어를 다시 내면 빼지 않음
  - 기록 순서는 처음 낸 때 기준 (다시 내도 순서가 안 바뀜)
  - 겹치면: 지금 최고는 늘 보이고, 처음 단어는 최고와 안 겹치면, 나머지는 최근 것부터 안 겹치는 것만. 숨은 말풍선 자리에는 아무것도 안 남김 (단어는 기록 표에 있음). 모두 같은 굵기, 글씨는 검정 (기록 표처럼 단어는 검정)
  - 실제 글자 폭과 카드 폭을 재서 판단 (`src/utils/progressMarks.ts`)

## 3. 배너 (방금 결과)

- 카드 윗줄, 테두리 없는 글자만: **아이콘 단어 순위 (유사도)** 순, 순위권 밖은 **아이콘 단어 점수**(`사과 12.30점`, 순위 자리에 유사도 점수). 아이콘은 평소와 다를 때만 맨 앞 (새로 낸 단어는 아이콘 없음). 단어가 늘 아이콘 다음이라 순위권 안팎이 섞여도 읽기 시작점이 그대로. 순위·점수는 단계 색 굵게, 순위권의 유사도는 맨 끝 괄호 안에 작고 옅게. 이름표 없이 순위만 `위`. 순위 밖은 순위 자리에 순위 밖 표시 (2026-11-15)
- **제출 횟수는 카드 오른쪽 위** (`n트`, 힌트·다시 내기는 안 셈). 옅은 회색 배지 + 굵은 진회색 글씨 (색은 안 씀: 파랑은 "가깝다" 뜻). 배너에는 번호 없음. 아직 안 냈으면 없음 (2026-11-15). 기록 표 `#` 칸은 "몇 번째로 낸 단어"(순서)라 그대로 `#`
- 위치는 따로: 게이지 막대 바로 위 **▼** 하나가 방금 단어 자리. 카드에서 움직이는 건 ▼뿐. 정답·포기는 ▼가 폭죽(✕) 위
- 글자 크기: 본문 크기(16px), 유사도 괄호 14px, 아이콘 16px. ▼와 안 겹치게 줄을 조금 위로 (2026-11-15)
- **글자만 가운데**: [아이콘 단어 순위 (유사도)]를 칸 폭 없이 이어 쓰고 실제 글자만 카드 가운데. 간격은 모두 6px. 글자 수가 바뀌면 그 차이의 절반만큼 움직임 (1글자 차이면 약 7px). 제출 횟수는 조금 위로 (2026-11-15)
- 게이지 위치가 없는 항목은 ▼ 없이 배너만 바뀜

| 방금 항목 | ▼ 자리 | 배너 |
| --- | --- | --- |
| 직접 낸 단어 | 그 순위 자리 (순위 밖은 맨 왼쪽) | 단어 순위 (유사도). 순위 밖은 단어 점수 (아이콘 없음) |
| 이미 낸 단어 다시 내기 | 그 순위 자리 | 맨 앞 반복 아이콘. 힌트 단어를 다시 내도 반복 아이콘 (`input/plan.md` 3-2) |
| 힌트 단어 | 그 순위 자리 (기록보다 가까우면 새 최고) | 맨 앞 전구 |
| 제출 중 (0.3초 넘게) | 없음 | 로딩 아이콘 + 단어 |
| 없는 단어 | 없음 | 정상 제출처럼 "단어 + 결과", 아이콘 없이 순위 자리에 순위와 같은 크기·굵기의 회색 글자 (단어 목록에 없는 단어, 오타 탓이 아님). 입력창은 비우고 placeholder 안내·오류 상태 없음 |
| 제출 실패 | 없음 | 경고 아이콘 + 짧은 실패 문구 (빨강, 알림, 굵기는 평소 단어와 같음). 단어는 입력창에 남아서 배너에는 안 씀. 입력창은 빨간 테두리·배경, 아래 문구 없음 |
| 초성 힌트 | 없음 | 전구 + 초성 + 순위 자리에 정답 표시(맞힘과 같은 파랑) + 작은 초성 표시 |
| 정답 맞힘 | 폭죽 자리 (▼가 폭죽 위) | 정답 + 순위 자리에 정답 표시 (파랑, 맞힌 폭죽·채움과 같은 색) |
| 포기 | 폭죽 자리 (✕로 바뀜, ▼가 ✕ 위) | 정답 + 순위 자리에 정답 표시 (회색) |
| 힌트·초성 힌트·포기 실패 | 그대로 | 방금 항목 대신 경고 아이콘 + 어떤 기능이 실패했는지 짧게 (빨강, 알림). 다음 요청이나 입력창에 글자를 치면 사라짐. 입력창은 그대로 (입력한 단어와 상관없는 실패라서) |
| 연속 실패 (어떤 요청이든 2번) | - | 배너는 위와 같고, 서버 문제로 보고 토스트를 한 번 띄움. 무엇이든 성공하면 횟수 초기화 |
| 처음 (아무것도 안 함) | 없음 | 배너 자리에 폭죽 컨셉으로 첫 입력을 부르는 안내 한 줄 (문구는 코드에서) |

- 배너가 바뀌어도 채움(최고 순위)은 그대로
- 게임이 끝난 뒤: 폭죽(맞힘)·✕(포기) 상태는 계속. 폭죽 위 정답은 방금 항목이 정답일 때만, 다음 단어를 내면 사라짐 (정답은 날짜 제목에 계속 보임). 말풍선·표시·채움은 진행 중과 같이 움직임

## 4. 접근성

- 카드는 이름 "방금 입력"인 영역(region)
- 배너는 상태(`role="status"`). 요청 실패 문구는 그 안의 알림(`role="alert"`): 새 항목이 오면 화면 읽기 프로그램이 읽음
- 게이지는 미터(`role="meter"`). 값 = 최고 순위의 게이지 위치(0~100), 값 글은 최고 순위
- 정답 자리 아이콘은 이름 있는 이미지: 진행 중 / 맞힘 / 포기마다 다른 이름
- 반복·전구·경고·없는 단어 아이콘 이름은 지금 방금 칸과 같게 (기존 테스트가 이름으로 찾음)

## 5. 표 자리

- 카드 높이가 방금 칸(머리줄 + 한 줄)과 달라지므로 표 자리 최소 높이(`word-list/plan.md` 5)를 헤드리스로 다시 잰다 (V-16)
