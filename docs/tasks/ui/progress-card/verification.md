# 진행 상황 카드: 검증

공통 원칙·레벨·mock 정책은 `../README.md`. 게이지 위치 계산(순위가 작을수록 정답 쪽, 칸 크기)은 `word-list/verification.md` RT-1이 로직으로 본다. 여기서는 화면에 무엇이 보이는지만 본다.

- 카드: 이름 "방금 입력"인 영역(`region`). 배너: 그 안의 상태(`status`). 게이지: 미터(`meter`), 값이 최고 순위 위치. 정답 자리: 이름 있는 이미지
- 미터 값은 "오른다 / 그대로다 / 0이다"만 본다 (정확한 값은 RT-1의 위치 계산)
- 문구는 보지 않고, 단어·순위·아이콘 이름만 본다
- 표시·말풍선 위치, 말줄임, 높이 고정, 모양은 시각이라 수동
