# 결과 상자 정리

게임이 끝났을 때(정답 맞힘·포기) 입력창 위에 뜨는 결과 상자에 대한 요구사항. (2026-11-13)

## 요구사항

1. 포기했을 때 결과 상자는 회색. 초록은 정답을 맞혔을 때만 쓴다 . 맞힘·포기 구분은 상자 색이 맡고, 날짜 제목의 정답 타일은 둘 다 파랑 (`word-list.md` 3-4)
2. 공유 버튼을 결과 상자 안에 둔다. 이름은 "도전장 보내기" → "공유하기", 위의 "친구는 나보다 빨리 맞힐까요?" 문구는 뺀다
3. 피드백 보내기 버튼을 결과 상자 안에 둔다. 설정 메뉴의 "피드백 남기기"와 같은 창을 연다
4. 정답 좋았다/별로였다 투표는 뺀다. 의견은 3의 피드백으로 받는다
5. 비로그인 로그인 안내는 문구만 남기고 로그인 링크는 뺀다. 헤더에 로그인 버튼이 바로 있음 (`plan.md` 8장을 바꿈)
6. 정답을 맞혔을 때 토스트는 띄우지 않는다. 토스트의 축하 멘트("축하합니다!", "N번째 시도에 정답을 맞히셨습니다.")는 결과 상자에 넣는다. 꽃가루는 그대로
7. 공유·피드백 버튼은 같은 모양으로 맞춘다 (같은 버튼 스타일, 아이콘도 같은 계열). 버튼 테두리·글씨는 상자 색을 따른다: 정답은 초록, 포기는 회색
