## 로그인 버튼 자리 (2026-11-13)

- 모바일(375px)에서 로그인 버튼이 오른쪽 묶음 맨 앞이라 화면 가운데쯤 떠 보였음 → 오른쪽 끝으로
- 로그인 말풍선을 버튼 오른쪽 끝에 맞추면서, 날짜 제목을 거의 다 가리던 것(V-17)이 줄어듦

## 로그인 버튼 색: 유지 (공지 색 정리 중)

- 고민: 메인에서 꽉 찬 파란 버튼이 로그인 하나라 강조가 세 보임. 로그인 권유는 말풍선도 하고 있음
- 해 본 것: classic만 파란 테두리(`border-blue-600 text-blue-600 hover:bg-blue-50`)로 낮춘 미리보기
- 결정: 꽉 찬 파랑(`bg-blue-600 text-white`) 유지. 로그인하면 기록이 남아 유저에게 이득이라 강조할 동작으로 봄 (원칙: 꽉 찬 파랑은 권하고 싶은 동작에만, `notices/decision.md` 색 원칙)

## 헤더 말풍선 5초 자동 닫힘 (2026-11-13)

- 배경: 날짜 제목을 입력창 위 가운데로 옮기면서(`word-list/plan.md` 4), 모바일(375px)에서 로그인 말풍선이 제목을 거의 다 가리게 됨 (V-17)
