## H-1. 헤더 말풍선 자동 닫힘 (`plan.md` 5)

사전 상태는 T와 같음. 로그인 말풍선은 닫기 버튼 "로그인 안내 닫기", 통계 말풍선은 "통계 안내 닫기"로 찾는다. 결과 상자 로그인 안내(H-2)는 `result-box/verification.md`.

| ID | 레벨 | 사전 상태 | 행동 | 기대 결과 |
| --- | --- | --- | --- | --- |
| H-1-1 | 화면 | 메인, 비로그인 | 진입 → 5초 미만 경과 → 5초 경과 | 5초 전에는 로그인 말풍선이 있고, 5초 뒤 사라짐. `login-tooltip-dismissed` 저장 |
| H-1-2 | 화면 | 메인, 로그인 | 진입 → 5초 경과 | 통계 말풍선이 사라지고 `stats-tooltip-dismissed` 저장 |
| H-1-3 | 화면 | 메인, 비로그인, 첫 방문 (모달 안 봄) | 진입 → 모달이 열린 채 5초 경과 → 모달 닫기 | 모달을 닫은 뒤 로그인 말풍선이 보임 (숨어 있는 동안은 세지 않음), 그 뒤 5초 지나면 사라짐 |
