# 헤더 (classic)

메인(`/`)과 `/stats` 헤더의 계정 영역, 헤더 말풍선. 내력은 `decision.md`.

## 1. 계정 영역: 로그아웃은 설정 메뉴로

- 헤더의 계정 영역
  - 비로그인: 로그인 버튼
  - 로그인: 닉네임만. 로그아웃 버튼은 헤더에 없다
  - 닉네임은 최대 폭 7rem(112px)에서 말줄임. 전체 닉네임은 `title`로 확인
- 설정 메뉴
  - 로그인 상태면 맨 아래 "계정" 영역에 로그아웃 버튼. 비로그인이면 영역 자체가 없다
  - 로그아웃 동작: `supabase.auth.signOut()` 후 새로고침
  - 회원 탈퇴 진입점도 나중에 이 영역에 붙인다 (`docs/tasks/withdrawal/plan.md`)
- excel 테마도 같은 `AuthButton` / `SettingsButton`을 써서 함께 바뀐다. excel 설정 메뉴에도 로그아웃이 있다
- 작은 화면(sm 미만) 보정: 이것만으로는 비로그인 상태도 넘쳐서(약 384px > 343px) 함께 적용
  - 부제 "단어 추측 게임" 숨김 (`hidden sm:block`)
  - 오른쪽 아이콘 간격 16px → 8px (`space-x-2 sm:space-x-4`)
  - 로고·부제 줄바꿈 방지 (`whitespace-nowrap`), 오른쪽 영역은 줄어들지 않게 (`shrink-0`)
  - `/stats` 헤더도 간격을 같이 줄인다

대략 폭 (375px, 사용 가능 약 343px)

| 상태 | 왼쪽 | 오른쪽 | 합계 |
| --- | --- | --- | --- |
| 비로그인 | 로고 약 72 | 로그인 56 + 아이콘 3개 96 + 간격 24 = 176 | 약 248 |
| 로그인 (긴 닉네임) | 약 72 | 닉네임 최대 112 + 96 + 24 = 232 | 약 304 |

## 2. 닉네임 색

- 검정 (`text-gray-900`). 닉네임은 눌리지 않는 글자라 파랑(로고와 겹치고 링크처럼 보임)이나 회색 대신 검정

## 3. 로그인 버튼 자리

- classic 헤더 순서: 규칙 · 통계 · 설정 · 로그인(로그인하면 닉네임). 오른쪽 끝
- 색은 꽉 찬 파랑 그대로 (`decision.md` 로그인 버튼 색)
- 로그인 말풍선은 버튼 오른쪽 끝에 맞춰 열림 (가운데 정렬이면 화면 밖으로 잘림)
- excel 테마는 그대로

## 4. 통계 유도 말풍선 (로그인 유저, 최초 1회)

비로그인 유저에게 로그인 말풍선을 띄우듯, 로그인 유저에게는 통계 페이지를 알려준다.

- 대상: 로그인 유저, 메인(classic) 헤더의 통계 아이콘 아래
- 모양·닫기는 로그인 말풍선과 같다: 말풍선 클릭 또는 X 버튼으로 닫고, 닫으면 다시 안 뜬다 (`localStorage` `stats-tooltip-dismissed`)
- 통계 페이지(`/stats`)에 한 번 들어가면 안내가 필요 없으므로 같은 키를 저장한다
- 비로그인 유저에게는 로그인 말풍선만, 로그인 유저에게는 통계 말풍선만 (동시에 뜨지 않음)
- 언제 보이는지(첫 방문 모달·입력창 말풍선 다음)는 `input/plan.md` 2 말풍선 순서

## 5. 헤더 말풍선 5초 뒤 자동 닫힘

- 헤더 말풍선(로그인·통계): 보이기 시작하고 **5초** 뒤 자동으로 닫힘
  - 5초는 실제로 보인 순간부터 센다. 첫 방문 모달·입력창 말풍선 때문에 숨어 있는 동안은 세지 않음
  - 자동으로 닫혀도 X로 닫은 것과 같이 저장 → 다시 안 뜸
- 로그인 안내는 결과창이 열릴 때마다 한 번 더 한다: 결과창이 열린 동안 헤더 로그인 버튼 강조 + 말풍선, 그동안 이 말풍선은 숨김(5초 카운트도 멈춤) (`result-box/plan.md` 8)
