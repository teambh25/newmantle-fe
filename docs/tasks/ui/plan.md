# 계획: 모바일 UI 정리 (classic)

출처: `docs/todo/ui.md`. 범위는 classic 테마의 메인(`/`)·통계(`/stats`) 헤더와 메인 공지사항.

## 1. 헤더 넘침 → 로그아웃을 설정 메뉴로 (후보 B)

### 결정

- 헤더의 계정 영역
  - 비로그인: 로그인 버튼 (그대로)
  - 로그인: 닉네임만 보여준다. 로그아웃 버튼은 헤더에서 뺀다
  - 닉네임은 최대 폭 7rem(112px)에서 말줄임. 전체 닉네임은 `title`로 확인
- 설정 메뉴
  - 로그인 상태면 맨 아래 "계정" 영역에 로그아웃 버튼을 둔다. 비로그인이면 영역 자체가 없다
  - 로그아웃 동작은 기존과 같다 (`supabase.auth.signOut()` 후 새로고침)
  - 회원 탈퇴 진입점도 나중에 이 영역에 붙인다 (`docs/tasks/withdrawal/plan.md`)
- excel 테마도 같은 `AuthButton` / `SettingsButton`을 써서 함께 바뀐다. 로그아웃이 헤더에서 빠지므로 excel 설정 메뉴에도 로그아웃이 있어야 한다

### 작은 화면 보정 (sm 미만)

B만으로는 비로그인 상태도 넘친다 (ui.md 계산: 비로그인 약 384px > 343px). 그래서 작은 화면에서만 아래를 함께 적용한다.

- 부제 "단어 추측 게임" 숨김 (`hidden sm:block`)
- 오른쪽 아이콘 간격 16px → 8px (`space-x-2 sm:space-x-4`)
- 로고·부제 줄바꿈 방지 (`whitespace-nowrap`), 오른쪽 영역은 줄어들지 않게 (`shrink-0`)
- `/stats` 헤더도 간격을 같이 줄인다

대략 폭 (375px, 사용 가능 약 343px)

| 상태 | 왼쪽 | 오른쪽 | 합계 |
| --- | --- | --- | --- |
| 비로그인 | 로고 약 72 | 로그인 56 + 아이콘 3개 96 + 간격 24 = 176 | 약 248 |
| 로그인 (긴 닉네임) | 약 72 | 닉네임 최대 112 + 96 + 24 = 232 | 약 304 |

## 2. 공지사항 글씨 한 단계 낮추기 => 추후 공지사항 페이지 분리 이후 재검토

`src/components/classic/NotificationFeed.tsx`

- 공지 제목 `text-lg` → `text-base`
- 본문 기본(`text-base`) → `text-sm`
- 영역 제목(`text-xl`)·날짜(`text-sm`)는 그대로

## 3. 입력창 위 게임 날짜에 요일 추가, 검정색으로

목적: 어제 문제를 풀고 있을 때 오늘 문제가 아니라는 걸 알아채게 한다.

- 형식: `11월 11일` → `11월 11일 (수)`
- 요일은 게임 날짜(KST `YYYY-MM-DD`)의 달력 요일. 기기 타임존과 무관해야 한다 (LA 기기에서도 KST 11/11이면 수요일)
- 색: `text-gray-400` → `text-gray-900`. 크기(`text-xs`)·굵기는 그대로
- 범위: classic. excel의 시트 이름(`Sheet: 11월 11일`)은 그대로

## 4. 힌트·포기 버튼에 글씨 추가 (프로토타입)

모바일은 마우스를 올리는 동작이 없어 툴팁이 안 뜨고, 아이콘만으로는 무슨 버튼인지 모른다. 최종 위치는 더 고민하기로 하고, 우선 아래 배치로 프로토타입을 만든다.

- 입력창 안의 아이콘을 빼고, 입력창 아래 오른쪽에 아이콘 + 글씨 버튼(`힌트`, `포기`)으로 둔다
- 입력창은 전체 폭을 쓴다 (오른쪽 여백 80px 제거)
- 글씨가 보이므로 툴팁은 뺀다. 접근 가능한 이름(`힌트` / `포기`)과 동작·비활성 규칙(`docs/spec/hint-giveup.md`)은 그대로
- 범위: classic

## 5. 로그인 유저에게 통계 페이지 유도 말풍선 (최초 1회)

비로그인 유저에게 로그인 말풍선("비로그인은 기록이 날아가요")을 띄우듯, 로그인 유저에게는 통계 페이지를 알려준다.

- 대상: 로그인 유저, 메인(classic) 헤더의 통계 아이콘 아래
- 문구 예: "내 정답 기록을 볼 수 있어요"
- 모양·닫기는 로그인 말풍선과 같다: 말풍선 클릭 또는 X 버튼으로 닫고, 닫으면 다시 안 뜬다 (`localStorage` `stats-tooltip-dismissed`)
- 통계 페이지(`/stats`)에 한 번 들어가면 안내가 필요 없으므로 같은 키를 저장한다
- 첫 방문 안내 모달이 열려 있는 동안은 숨기고, 닫힌 뒤에 보인다 (로그인 말풍선의 M-6과 같음)
- 비로그인 유저에게는 로그인 말풍선만, 로그인 유저에게는 통계 말풍선만 뜬다 (동시에 뜨지 않음)

## 6. 헤더 닉네임 색

- `text-gray-700` → `text-gray-900` (검정)
- 파랑은 로고와 겹치고 눌리는 링크처럼 보이는데, 닉네임은 눌리지 않는 글자라 검정으로 한다
