# 실제 폰 확인

개발자 도구 모바일 화면으로는 확인할 수 없는 것 (키보드, 실제 보이는 높이). iOS Safari와 Android Chrome에서 한 번에 몰아서 본다.

| ID | 확인할 것 | 기기 | 원래 기능 |
| --- | --- | --- | --- |
| VM-1 | 키보드 엔터 키가 "보내기"로 보이고 눌러서 제출됨. 연속으로 단어를 낼 때 키보드가 내려가지 않음 (V-10, V-21에서) | iOS / Android | `input/` |
| VM-2 | 없는 단어를 낸 뒤(입력창 비워짐)와 제출 실패 뒤(단어 남음) 모두 키보드가 내려가지 않고 바로 다음 글자를 칠 수 있음 (V-19에서) | iOS / Android | `input/` |
| VM-3 | 한 화면에 입력창과 함께 단어 목록이 몇 줄 보이는지 → 보이는 개수 최종값 결정 (V-15에서) | iOS / Android (작은 폰 포함) | `word-list/` |
| VM-4 | 첫 방문 안내 모달을 "시작하기"로 닫으면 iOS에서 키보드가 올라옴 (V-11에서) | iOS | `input/` |
