## 1. 문제

- **(a) 맨 위가 1등으로 읽힘**: 방금 입력 칸은 가장 최근 행동(입력·힌트·초성·포기)인데, 아래 기록 표가 순위순이라 맨 위를 "지금까지 가장 가까운 단어"로 읽기 쉽다. 순위를 잘못 알면 다음 단어 판단이 틀어짐
- **(b) 단어가 사라진 느낌**: 다음 행동을 하면 방금 칸의 단어가 기록 표 중간 순위 자리로 들어가 놓치기 쉽다
- **가까워지는 느낌이 없음**: 줄 배경 단계로 "지금 어디쯤"은 보이지만, 시도를 거듭하며 정답에 다가가는 흐름은 안 보인다
- 전제: 사용자는 엔터 뒤 입력창이 아니라 표 맨 위를 본다. 확인할 정보는 방금 칸에 다 들어 있다 (`input/plan.md` 3)

## 2. 방금 입력 꼬리표

- 한 번 알려 주는 말풍선 대신 **늘 보이는 표시**. (a)·(b)는 매 판 생기고, 말풍선은 이미 셋(모달 → 입력창 → 헤더)이라 더하면 첫 제출 순간 겹친다
- 자리: **굵은 구분선 오른쪽 끝, 선에 걸친 작은 꼬리표**. 위쪽은 "방금"을, 아래쪽은 "순위순"을 가리키는 짧은 글자 + 화살표
  - 아래가 순위순이라고 같이 적어 맨 위가 1등이 아님을 알림 (a), 방금 칸 단어가 순위 자리로 들어가는 흐름도 읽힘 (b)
  - 표 높이가 안 늘어 최소 높이(365px)·푸터 위치(V-16) 그대로. 왼쪽은 트랙 자리로 비움
  - 다른 후보: # 칸(이미 번호·반복·전구·깃발·"-"·경고로 꽉 참), 줄 왼쪽 띠(트랙과 자리 다툼), 머리줄 위 글자 줄(높이 늘고 방금 줄과 멂)
- **시작부터 둘 다 보임** (가리킬 줄이 없어도). 자리가 고정돼 눈에 익음

## 3. 순위 글씨 색

- 줄 배경색은 쓰지 않는다. 색은 **글씨만**
- 두 구간을 이어 붙임. 경계는 **100위**
  - 회색 구간: 순위 밖 → 301–999 → 101–300 순으로 짙어짐. 끝은 **진한 회색**에서 멈춤 (검정까지 가면 다음 파랑 중간색이 오히려 덜 진해 보여 흐름이 뒤집힘)
  - 파랑 구간: 51–100 → 21–50 → 1–20 순으로 진해짐
  - 흰 배경 글씨라 가장 옅은 색도 읽혀야 함 (파랑은 중간 파랑부터, 회색은 `gray-500`부터: 흰 바탕 대비 4.5:1 이상. 2026-11-15에 `gray-400`(약 2.5:1)에서 올림)
- 칠하는 칸: **순위 + 유사도**. 단어는 검정 그대로 (다음 수의 재료라 또렷하게, 힌트 단어 갈색 글씨와 안 부딪힘). 유사도는 지금 늘 회색 → 순위와 같은 색
- 아이콘은 모두 **검정** (힌트·초성 전구도). 힌트 줄은 단어 갈색 글씨로 구분

## 4. 순위 트랙

목표: 게임 중에는 가까워지는 느낌, **게임이 끝났을 때 내 플레이 과정을 한눈에 요약**.

### 4-1. 막대

- 표 왼쪽 세로 막대. 눈금을 다 그리지 않고 **색 단계 칸**으로 나눔 (3장 경계: 순위 밖 / 301–999 / 101–300 / 51–100 / 21–50 / 1–20). 칸 경계가 곧 눈금, 숫자는 경계 몇 개만
  - 같은 간격(1–1000)이면 1–20위가 막대의 2%(약 7px)라 가장 긴장되는 구간이 안 보임. 로그 간격은 숫자가 색 단계와 따로 놂
  - 정답 쪽 칸일수록 크게. 칸 안에서는 고르게 (칸 안에서 조금 올라가도 점이 움직임)
  - 순위 밖은 맨 아래 작은 칸 (그 안에서 위치는 안 바뀜)
  - 칸 색은 3장 글씨 색과 같은 뜻
- 맨 위(1위 칸 위)에 **끝점(정답)** 자리. 처음부터 빈칸으로 보여 목표 방향을 줌
- 높이는 **고정** (접힌 표 영역 정도). "더보기"로 표를 펼쳐도 그대로 → 요약 모양이 늘 같고 V-16 유지. sticky는 안 함

### 4-2. 갱신 길

- 최고 순위가 갱신될 때마다 그 순위 자리에 표시를 남기고 **표 #(시도 번호)**를 옆에 적는다. 표시를 선으로 이어 길로
  - 세로 막대에 시간 축이 없는 대신, 아래에서 위로 #가 커지며 "몇 번째에 여기까지"가 읽힘. #로 표 줄을 찾아갈 수 있음
  - 모든 단어 흔적은 안 찍음 (단어가 쌓이면 겹침)
- **시작은 첫 제출부터**: 첫 단어가 순위 밖이면 순위 밖 칸에 첫 #. 다른 순위 밖 단어는 갱신 아님. 처음 순위권에 든 단어에서 선이 올라감 → 순위권에 들기까지 헤맨 구간이 보임. 처음부터 순위권이면 순위 밖 칸은 빈 채로
- **힌트**: 힌트는 늘 최고 순위보다 가까워(hint-giveup A-7) 항상 갱신. # 자리에 **검정 전구** (표 # 칸과 같은 기호). 막대 최고 순위와 표 1등이 늘 같음
- **초성**: 순위를 안 바꾸므로 트랙에 표시 없음
- **끝점**
  - 정답을 맞힘: 길이 끝점까지 **이어지고** 끝에 시도 횟수("n트" 식)
  - 포기: 마지막 최고 순위에서 길이 **끊기고** 끝점은 빈 채로
- 글자가 겹칠 때(같은 칸에 갱신이 몰릴 때): **오래된 쪽 글자를 숨기고 눈금만**. 단, 시작(첫 #)·처음 순위권 진입·마지막 갱신·끝점은 늘 보임. 겹쳐서 위로 밀면 순위 자리와 어긋나서 안 씀
- 게임이 끝나도 메인에서는 같은 규칙 (숨은 #는 옆 표에서 찾음). 자세히 보기는 5장

### 4-3. 방금 점

- 방금 칸이 **순위가 있는 단어**(직접 낸 단어, 다시 낸 단어, 힌트)일 때만 막대에 점. 색은 그 순위의 글씨 색
- 없는 단어·제출 실패·초성일 때는 점 없음 (꼬리표는 그대로)
- 최고 순위를 갱신하면 갱신 표시와 같은 자리 → 갱신 표시가 보이고 점은 겹침 (갱신 순간 짧은 강조는 선택)
- 게임이 끝나면 점 없음 → 남는 건 길과 끝점 (요약)

### 4-4. 모바일 폭

트랙은 막대·점·#글자로 최소 36–40px. 모바일 폭 343px에서 지금 # 48 / 단어 약 135 / 순위 80 / 유사도 80.

- **순위·유사도 각 72px, # 40px**로 줄여 24px, 나머지 약 16px는 단어 칸에서 → 단어 칸 약 119px (6글자 안팎)
- "순위 밖"·"999위"·"100.00"·세 자리 시도 번호가 들어가는지 헤드리스 360·375px로 잰다. 부족하면 트랙 글자 12px
- 최후 수단: # 칸 없애기, 또는 모바일에서 트랙 빼기·가로 막대
