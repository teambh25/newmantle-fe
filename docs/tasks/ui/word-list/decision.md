# 단어 목록: 결정 기록

## 시작할 때 상태와 문제 (2026-11-11)

- 정렬: 가장 최근 항목 하나를 맨 위에 고정하고, 나머지는 순위 오름차순, 순위 밖은 유사도 내림차순

| 종류 | 구분 방법 | 그때 표시 |
| --- | --- | --- |
| 내가 입력한 단어 | `attempt` ≥ 1 | # 칸에 번호 |
| 힌트 단어 | `attempt === -1` | # 칸에 전구 아이콘 (검정), 나머지는 입력 단어와 같음 |
| 초성 힌트 | `attempt === -1`, `rank === 0` | # 전구, 순위 "초성", 유사도 칸 "힌트" (파랑 굵게) |
| 정답 | `correct` | 줄 배경 연두 (`bg-green-50`), 순위 "정답!" |

- 줄 배경: 맨 위(방금 입력) `bg-muted` + `font-medium`, 정답 `bg-green-50`
- 순위 칸 글자색 3단계: 1–10 `blue-600` 굵게, 11–100 `blue-500` 약간 굵게, 101 이상 `gray-600`, 순위 밖 `gray-400`
- 기본 5줄, 6개 이상이면 "더보기"

문제

- 순위 구분이 안 됨: 1–10과 11–100이 둘 다 파란 글씨라 진하기 차이가 거의 안 보임. 단계도 3개뿐
- 방금 입력한 단어가 강조가 안 됨: 연회색 배경뿐이고 아래 목록과 경계가 없어 정렬된 1등처럼 보임
- 힌트 단어가 강조가 안 됨: # 칸 전구(검정)만 다름
- 초성 힌트가 순위처럼 보임: `rank === 0`이라 정렬하면 항상 위에서 두 번째. 파란 굵은 글씨라 상위 순위와 헷갈림
- 5줄은 적음
- 단어를 넣을 때마다 아래(푸터)가 밀림

## 순위 표시 (2026-11-11)

- 1차 배지안: 순위 칸 배지 → 화면 확인 후 2차로
- 2차: **줄 전체 옅은 배경**. 테두리·파란 글씨·굵게 제거. 경계값 20 / 50 / 100 / 300
- (2026-11-13 이후 `rank-track.md`: 배경은 빼고 글씨 색만, 회색 → 파랑 두 구간으로 바꿀 예정)

## 방금 입력한 단어

- 1차: 연회색 배경 제거, **굵은 구분선만** (2026-11-11)
- 맨 위 고정 줄의 정의 (2026-11-13)
  - 처음: 정답을 맞힌 직후·초성을 방금 받은 경우 맨 위 고정 줄 없이 정렬 목록만
  - 고정 줄이 사라지면 순위 1등 단어가 우연히 맨 위에 와서 반복 아이콘이 남는 등 헷갈렸고(리뷰에서 발견), 끝난 뒤에 마지막에 무엇을 했는지 안 보였음
  - 사용자 정의: 구분선 위는 가장 최근에 입력한 단어의 상태. 이어 "직접 입력한 단어 or 힌트"로 정하고, 초성·정답도 기록 표에는 안 적혀도 구분선 위에는 한 줄로 → 가장 최근 항목(입력·힌트·초성·정답)
  - 힌트도 구분선 위에 두는 게 일관됨 (힌트는 늘 가장 높은 순위라 구분선 바로 아래에 오긴 하지만, 위 칸은 "가장 최근"이라는 뜻을 지킴)
  - 구분선은 게임 시작부터 끝까지 둔다
- **표를 둘로 나눔** (2026-11-13)
  - 같은 표 안의 굵은 구분선일 때는 맨 윗줄이 사라졌다가 아래에 나타나 보였다. 칸을 나누면 "방금 칸 → 기록으로 옮김"으로 읽힘
  - 처음엔 같은 단어가 위 칸과 기록 표에 동시에 보임 → "다음 항목이 올 때 기록 표로 옮김"으로 (사용자 요청)
  - 처음엔 네 면을 다 막은 둥근 상자 + 간격 → 기록 표와 따로 노는 느낌이라 좌우를 열고, 간격을 없애 붙이고, 아래 선을 예전 구분선처럼 굵게
  - 시작할 때 "아직 제출한 단어가 없습니다" 문구 대신 빈 표
- 초성·정답 줄 모양: 처음엔 순위·유사도 칸을 합친 한 칸 → 없는 단어 임시 줄과 같이 4칸으로. 유사도 칸이 회색이라 어색해 보통 글씨 색으로

## 초성·날짜 제목

- 초성 노란 배지 → **입력창 위 날짜 줄로**, 게임이 끝나면 숨김 (2026-11-11)
- 날짜 줄에 요일 추가, 검정 (2026-11-11): 어제 문제를 풀고 있을 때 오늘 문제가 아니라는 걸 알아채게. 형식 `11월 11일 (수)`, 색 `text-gray-400` → `text-gray-900`
- **가운데 두 줄 제목**으로 (2026-11-13)
  - 요일을 풀어 씀: 괄호 `(금)`는 다른 말 옆에 붙을 때 쓰는 줄임이라 혼자 있는 줄에서는 딱딱함
  - "오늘의": 크게 쓴 둘째 줄만 읽어도 뜻이 통하게. UI에 어제 문제를 여는 기능이 없어 틀릴 일 없음
  - 초성 사용 후 "은"을 빼서 질문 → 답이 걸린 이름표로
  - 게임이 끝나면 초성 대신 정답 (이전 결정 "끝나면 숨김"을 대체)
- 타일 색
  - 처음: 초성 노랑(힌트 단어 글자색) / 정답 맞힘 초록 / 포기 회색
  - 결과 상자가 맞힘 초록·포기 회색이 되면서 상자 바로 아래 같은 색 타일이 겹쳐 보여 어색함 → 정답 타일은 맞힘·포기 모두 파랑
  - 초성도 정답의 일부라 같은 파랑. 진행 중 `[ㅅ][ㄹ]`이 끝나면 같은 타일에서 `[사][랑]`으로 채워짐. 노랑의 근거(목록의 힌트 글자색)는 초성이 목록에서 빠지면서 약해짐. 회색은 비활성처럼 보이고 포기 상자 색과 겹쳐서 버림
  - 처음에 파랑을 뺀 이유(목록의 파랑 = 정답과의 거리, 버튼의 파랑 = 누르는 요소)는 연한 바탕 + 진한 글씨로 버튼과 구분해 감수
- 크기: 처음보다 한 단계씩 키움. 헤더와 붙어 보여서 제목 위 여백
- **정답은 순위표에서 뺌**: 제목에 정답이 보이므로 표의 정답 줄(연두, "정답!")은 중복. 몇 번 만에 맞혔는지는 결과 상자에 있음. 포기한 정답 항목의 번호가 마지막 입력 번호와 겹쳐 보이던 것도 함께 사라짐
- 포기 저장 시 `gameCompleted`도 true라 포기 판단을 `givenUp` 먼저 보도록 함 (구현 중 발견)
- 정답이 제목 타일에서 글자별로 나뉘어 한 단어로 안 찾아지던 것 → 스크린 리더용 한 단어(`sr-only`) + 타일 `aria-hidden`
