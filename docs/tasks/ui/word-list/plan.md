# 단어 목록 (classic)

입력창 아래 단어 목록(표)과 입력창 위 날짜·정답 제목. 내력은 `decision.md`. 다음 단계(방금 입력 꼬리표, 순위 글씨 색, 순위 트랙)는 `rank-track.md`.

## 표시 수단마다 뜻 하나

| 표시 | 뜻 |
| --- | --- |
| 줄 배경 | 정답과의 거리 (파랑 단계) → `rank-track.md`에서 글씨 색으로 바뀔 예정 |
| 글자 스타일 | 출처. 힌트 단어는 갈색 글자, # 칸에 전구 |
| 방금 입력 칸 | 가장 최근 항목 (아래 기록 표는 순위순) |
| 입력창 위 가운데 제목 | 초성, 끝나면 정답. 둘 다 기록 표에는 없음 |

색 원칙: 초록은 정답 전용, 빨강·주황은 쓰지 않음 (멀다는 느낌 → 포기 유도). 힌트·포기 버튼을 검정으로 정한 것과 같은 이유. classic 테마는 다크 모드가 없어서 라이트만.

## 1. 표 구조: 방금 입력 칸과 기록 표

```
          11월 13일 금요일
         오늘의 정답 [ㅅ][ㄹ]
 ──────────────────────────────────
   #    단어          순위    유사도      ← 머리줄 (방금 입력 칸에 하나만)
  17    햇볕          37위    35.60      ← 방금 입력 칸
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━      ← 굵은 선 (2px)
  16    봄비           3위    55.31      ← 기록 표 (순위순)
  💡    새싹          24위    38.90
  12    바람          45위    34.80
```

- 위는 **방금 입력 칸**(머리줄 + 한 줄, 이름 "방금 입력"인 표), 아래는 **기록 표**(이름 "기록"인 표, 순위순)
  - 방금 입력 칸은 위아래 선만: 위 옅은 회색 1px, 아래 굵은 선(2px, `gray-400`). 좌우 선 없음. 기록 표와 간격 없이 붙음
  - 두 표의 칸 폭을 맞춘다
- 방금 입력 칸 = **가장 최근 항목** 하나

| 방금 입력 칸에 오는 것 | 번호 칸 | 단어 칸 | 순위·유사도 칸 | 다음 항목이 오면 |
| --- | --- | --- | --- | --- |
| 직접 낸 단어 | 시도 번호 | 단어 | 순위·유사도 | 기록 표 순위 자리로 |
| 이미 낸 단어 다시 내기 | 반복 아이콘 (`input/plan.md` 3-2) | 단어 | 순위·유사도 | 기록 표 자기 자리, 원래 번호로 |
| 힌트 단어 | 갈색 전구 | 갈색 글자 | 순위·유사도 | 기록 표 순위 자리로 |
| 초성 힌트 | 갈색 전구 | 초성 (갈색 글자) | 종류 / 100 | 어디에도 안 남음 (제목에 보임) |
| 정답 맞힘 | 시도 번호 | 정답 | 종류 / 100 | (게임 끝, 그대로 남음) |
| 포기 | 깃발 아이콘 | 정답 | 종류 / 100 | (게임 끝, 그대로 남음) |
| 없는 단어 · 제출 실패 | "-" / 원 경고 아이콘 | 친 단어 | 상태 (`input/plan.md` 3-1) | 어디에도 안 남음 (저장 안 함) |
| 제출 중 (0.3초 넘게 걸릴 때) | 다음 시도 번호 | 친 단어 | 스피너, 줄 전체 회색 | 응답으로 바뀜 |

- 한 단어가 두 곳에 동시에 보이지 않는다. 방금 입력 칸의 단어는 다음 항목이 올 때 기록 표로 옮긴다
- 초성·정답 줄은 보통 줄처럼 4칸. 유사도 칸은 보통 글씨 색
- 방금 입력 칸은 게임 시작부터 끝까지 늘 있다 (단어가 1개여도, 게임이 끝나도). 끝난 뒤에도 마지막으로 무엇을 했는지 보이게
- 시작할 때는 빈 표(머리줄 + 굵은 선)를 바로 보여 준다 (안내 문구 없음)
- 방금 입력 칸 배경은 거리 색 그대로 (회색 배경을 두면 "배경 = 거리"가 깨짐)
- 기록 표 정렬: 순위 오름차순, 순위 밖은 유사도 내림차순 (`compareByRank`). 초성·정답은 기록 표에 넣지 않는다 (4, 제목에 보임)

## 2. 순위 단계 (줄 배경)

- 줄 전체를 옅은 파랑으로. 가까울수록 진하게. 배지·테두리·파란 글씨·굵게는 쓰지 않음 (번잡함)
- 막대(유사도 바)는 원작과 겹쳐서 쓰지 않음

| 순위 | 줄 |
| --- | --- |
| 1–20 | 가장 진한 파랑 배경 |
| 21–50 | 중간 파랑 배경 |
| 51–100 | 옅은 파랑 배경 |
| 101–300 | 아주 옅은 회청색 배경 |
| 301–999 | 배경 없음, 순위 글자 회색 |
| 순위 밖 | 배경 없음, 순위 글자 연회색 |

- 첫 경계 20 = 힌트 한계 순위(`docs/spec/hint-giveup.md` A-6, `HINT_LIMIT_RANK`). 20위 이내는 힌트로 받을 수 없는 "아주 유사" 구간이라 가장 진하게
- 유사도 칸은 회색 한 가지. `Similarity.tsx`는 excel 테마도 쓰므로 건드리지 않고 classic 표 안에서만 처리
- 경계값은 순위 → 단계 함수 하나(`src/utils/rankTier.ts`)

## 3. 힌트 단어

- 단어 글자를 갈색 계열(`amber-700`, 굵게), # 칸에 갈색 전구 아이콘(`Lightbulb`, `amber-700`, 이름 "힌트로 받은 단어")
- 이탤릭은 쓰지 않음 (한글 기울임은 억지로 비틀린 모양)
- 줄 배경은 입력 단어와 같은 거리 색 (실제 순위가 있음)

## 4. 날짜·정답 제목

입력창 위 **가운데 두 줄 제목**. 정답이 `?` → 초성 → 정답 순으로 드러나는 한 문장.

```
            11월 13일 금요일            ← 작게, 회색
         오늘의 정답은?                 ← 크게, 굵게 (초성 사용 전)
         오늘의 정답 [ㅅ][ㄹ]           ← 초성 사용 후: 파란 타일
         오늘의 정답 [사][랑]           ← 게임 끝(맞힘·포기): 파란 타일
```

- 첫 줄 날짜: 요일을 풀어 씀 (`11월 13일 금요일`). 요일은 게임 날짜(KST `YYYY-MM-DD`)의 달력 요일이라 기기 타임존과 무관 (`formatGameDate`, classic만 씀)
- 둘째 줄: 초성 사용 전 질문, 사용 후 "정답 + 타일" 이름표. 글자마다 타일 (글자 수가 보임). 초성 사용 전에는 글자 수를 알려주면 안 되므로 타일 없이 `?`
- 타일 색: 초성·정답 모두 파랑 (`bg-blue-100` + `text-blue-700`). 제목 글자는 검정·회색 그대로. 맞힘·포기 구분은 결과 상자 색이 맡음 (`result-box/plan.md` 1)
- 스크린 리더는 정답을 한 단어로 읽게: 제목에 `sr-only` 한 단어, 타일은 `aria-hidden`
- 게임이 끝나면 초성 대신 정답 (저장된 기록의 `correct` 항목, 맞힘·포기 모두 저장됨)
- 크기: 날짜 `text-sm`(sm `text-base`), 둘째 줄 `text-xl`(sm `text-2xl`). 제목 위 여백 `mt-4`(sm `mt-6`)
- 높이 고정: 초성·정답 타일이 생겨도, 날짜를 불러오기 전에도 제목 높이 그대로
- 저장 데이터(`submittedWords`의 `rank: 0` 항목)는 그대로 두고 표시만 바꿈 → 기존 저장 데이터 호환
- 범위: classic. excel의 시트 이름은 그대로

## 5. 보이는 개수와 표 자리

- **7줄**: 방금 입력 칸 1줄 + 기록 표 6줄 (`VISIBLE_HISTORY_COUNT`). 기록이 6개를 넘으면 "더보기" / "접기"
  - 방금 입력 칸이 기록 표에 안 들어가는 항목(초성·정답·임시 줄·제출 중)이어도 칸 하나를 차지하므로 기록 6줄 기준 그대로
- **표 자리 확보**: 단어가 적어도 표 영역이 7줄 + "더보기" 높이를 차지하도록 최소 높이(`min-h-[365px]`). 빈 줄이 아니라 공백. 플레이 중에 아래 내용(푸터 등)이 움직이지 않게
  - "더보기"로 펼치면 그만큼 길어지는 건 그대로 (사용자가 직접 누른 것)
- 표와 푸터 사이 공백 40px (게임 영역 아래 여백 없음, 푸터 위 `mt-6`)
- jsdom은 높이를 계산하지 않아 자동 테스트 불가 → 헤드리스 크롬으로 단어 개수별 푸터 위치 측정 (V-16)
