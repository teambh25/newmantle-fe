# 공지 띠 라벨 / 공지 배지 색 (classic)

공지 페이지 분리(`notices.md`) 후 나온 고민. 결정은 맨 아래.

## 문제

- 메인 맨 위 공지 띠(announcement bar)는 옅은 파란 배경(`bg-blue-50`)인데, 종류 라벨("업데이트")도 파란 글씨(`text-blue-600`), 제목은 남색(`text-blue-900`) → 파랑 세 단계가 겹쳐 라벨이 어색함
- `/notices`의 종류 배지는 옅은 배경 + 진한 글씨 색 배지 (업데이트 초록 / 공지 파랑 / 이벤트 보라, `getTypeColor`)
  - 공지 6개 중 5개가 업데이트라 색 구분이 별 의미 없이 초록만 반복돼서 어색함
- 같은 "업데이트"가 띠(파랑)와 `/notices`(초록)에서 색이 다름
- 띠 배경은 지금 파란색이 자연스러워서 유지하고 싶음

## 후보

| 후보 | 띠 배경 | 띠 라벨 | `/notices` 배지 | 장점 | 단점 |
| --- | --- | --- | --- | --- | --- |
| 지금 | 옅은 파랑 | 파란 글씨 | 옅은 색 배지 (초록 / 파랑 / 보라) | — | 파랑 위 파랑 라벨이 어색. 두 곳의 색이 다름 |
| A. 띠를 배지에 맞춤 | 연회색 | 기존 색 배지 | 그대로 | 두 곳 색이 같음 | 파란 띠 포기. 어색한 배지 색은 그대로 |
| B. 배지 색 빼기 | 옅은 파랑 | (따로 정해야 함) | 무채색 | 차분함 | 띠는 별도 결정 필요 |
| C. 띠 라벨만 무채색 | 옅은 파랑 | 굵은 진한 글씨 | 그대로 | 띠만 정리 | 같은 "업데이트"가 띠는 무채색, 페이지는 초록이라 따로 놂 |
| D. 진한 단색 배지 | 옅은 파랑 | 진한 단색 배지 (업데이트 `blue-600` / 공지 `gray-700` / 이벤트 `amber-500`, 흰 글씨) | 같은 배지 | 두 곳 완전히 같음. 업데이트가 대표색 파랑이라 띠와 같은 계열 | 파란 띠 위에 색 배지가 올라감 (지금 어색한 지점) |
| **E. 추천** | **옅은 파랑 (그대로)** | **굵은 진한 글씨** (`업데이트 │ 제목`) | **무채색 배지 하나로** (`bg-gray-100 text-gray-600`) | **두 곳 모두 "종류는 글자로, 색은 안 씀"으로 맞춰짐. 파란 띠 유지** | 종류를 색으로 한눈에 구분 못 함 (대부분 업데이트라 영향 작음) |

## 메모

- 띠 라벨을 흰 글씨로 하는 안은 제외: 옅은 파란 배경 위 흰 글씨는 대비가 낮아 잘 안 읽힘. 검정(진한 색) 굵게가 나음
- E로 가면 `getTypeColor`는 쓰는 곳이 없어져 삭제 → 장애 배지 색 때문에 남김
- C·E 모두 라벨과 제목 사이에 얇은 구분선이나 간격을 두면 굵기만으로 구분됨
- 색은 `src/utils/notifications.ts` 한 곳에서 정해서 띠와 `/notices`가 같이 바뀌게 유지

- `src/components/classic/NotificationFeed.tsx`: `/notices` 배지

## 결정

- [x] E를 바탕으로, 장애 종류만 색을 쓴다

원칙: 기본은 파랑과 무채색. 다른 색은 경고처럼 뜻이 있을 때만 쓴다 (포기 선택지의 빨강, 통계의 정답·실패 색과 같은 기준). 공지 종류는 강조할 정보가 아니라 글자로 충분하고, 장애만 주의가 필요하다.

공지 종류도 함께 정리: 업데이트 / 공지 / 장애(신규), 이벤트 삭제. 종류 규칙은 `docs/spec/notices.md`

| 곳 | 평소 (업데이트·공지) | 장애 |
| --- | --- | --- |
| 메인 띠 배경 | 옅은 파랑 (`bg-blue-50`) | 옅은 빨강 (`bg-red-50`) |
| 메인 띠 라벨 | 굵은 검정 (`text-gray-900`) | 굵은 빨강 (`text-red-700`), 라벨은 "안내" |
| 메인 띠 제목 | 회색 (`text-gray-700`) | 진한 빨강 (`text-red-900`) |
| `/notices` 배지 | 회색 (`bg-gray-100 text-gray-600`) | 옅은 빨강 (`bg-red-50 text-red-700`) |

비교해 보고 뺀 것
- 띠 라벨 파랑(`text-blue-700`): 파란 배경 위 파랑이라 겹쳐 보임
- 띠 제목 남색(`text-blue-900`): 파랗게 보여 회색으로. 장애 띠는 강조가 목적이라 빨강 유지
- 장애 띠 제목 회색: 빨간 제목이 더 잘 보여서 되돌림
- 진한 파랑 띠 + 흰 글씨: 강조는 세지만 매일 하는 게임 위에서 띠가 너무 먼저 보임
- 업데이트 배지 초록: 통계의 정답 색과 뜻이 겹치고, 공지 대부분이 업데이트라 초록만 반복
