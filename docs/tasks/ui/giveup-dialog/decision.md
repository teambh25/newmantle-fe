# 포기 확인 창: 결정 기록 (2026-11-12)

색 정리(`notices/decision.md` 색) 중에 나온 고민.

- 포기 버튼 색: 빨강(`destructive`) → 회색 테두리. 파랑·빨강 둘 다 꽉 찬 버튼이라 시선이 나뉘고, 빨강이 오히려 눈에 띔
- 버튼 위치
  - 증상: 모바일에서 버튼이 코드 순서와 반대로 쌓여 포기가 맨 위에 옴
  - 원인: 공통 `DialogFooter`가 `flex-col-reverse sm:flex-row` ("주요 버튼을 마지막에 둔다"는 가정)
  - 계속 플레이 쪽을 마지막에 (웹에서 흔한 배치)
- 첫 번째 창 질문
  - 문제: 제목이 "정말 포기하시겠습니까?"라 "예" = 포기 → "진행은 오른쪽" 관례로는 포기가 오른쪽이어야 할 것 같음. 그런데 유도하고 싶은 건 초성 힌트
  - 제목을 초성 힌트를 권하는 질문으로 바꿔 초성 힌트가 "진행"이 되게
- 초성 없이 계속하기
  - 문제: "초성 힌트 없이 계속"은 X(창 닫기)뿐이라 X를 누르면 어떻게 되는지 헷갈림
  - 처음엔 PC도 가운데 정렬이라 어색했음 → PC 오른쪽
  - 창이 한 줄만큼 커져서 위 버튼과 간격을 8px로 줄임
  - 화면 확인용으로 먼저 넣어 본 뒤 채택 (B-2-1 실패 상태에서 채택 → 케이스 수정)
- 간격·폭: 설명과 버튼이 붙어 PC에서 답답함. 모바일에서 설명이 단어 중간에서 줄바꿈(한국어 기본). 창이 모바일에서 화면 끝까지 붙음
- 성공 토스트: 위치가 모바일은 화면 위라 게임을 가림 (공통 설정이라 위치는 그대로) → 토스트를 뺌
- 모바일 정렬: 공통 `DialogHeader`가 `text-center sm:text-left`라 모바일에서 가운데 정렬 → 이 창은 왼쪽 고정. 설명은 쉼표 뒤 줄바꿈만으로는 360px에서 뒷부분이 다시 두 줄이 돼서 줄임
- 초성 힌트 위치 변경은 그때 고민 중이었음 → 날짜 제목으로 감 (`word-list/plan.md` 4)
