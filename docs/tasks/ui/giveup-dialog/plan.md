# 포기 확인 창 (classic)

스펙: `docs/rules/hint-giveup.md` B-2, C-2. 내력은 `decision.md`.

- 범위: classic. excel은 그대로 (`docs/specs/excel-ui/plan.md`)
- 이 창의 목적은 경고보다 계속 플레이로 유도. 단, 포기 버튼은 잘 보이고 이름이 분명해야 한다. 죄책감을 주는 문구(confirmshaming)는 쓰지 않는다

## 1. 포기 버튼 색

- 포기 쪽은 회색 테두리(`outline`). 계속 플레이 쪽만 꽉 찬 파랑
- 되돌릴 수 없다는 경고는 제목·설명이 맡는다

## 2. 버튼 위치

- 계속 플레이 쪽을 코드상 마지막에 → PC 오른쪽, 모바일 위
- 두 창(초성 미사용 / 사용 후) 모두 계속 플레이 쪽이 같은 자리. 같은 자리를 눌렀는데 한 창에선 계속, 다른 창에선 포기가 되면 안 됨

## 3. 첫 번째 창(초성 미사용): 초성 힌트를 권하는 질문

- 제목은 포기하기 전에 초성 힌트를 받아 보겠냐는 질문. 초성 힌트가 "진행"이 된다
- 선택지: 초성 힌트 받기(강조, 오른쪽·위) / 포기하고 정답 보기(덜 강조). 무슨 일이 생기는지 버튼 이름에 드러나게
- 두 번째 창(초성 사용 후)은 진짜 포기 확인: 정말 포기할지 묻고, 계속 도전하기 / 포기하기

## 4. 초성 없이 계속하기

- 첫 번째 창에만, 두 버튼 아래에 작은 회색 밑줄 글씨 버튼 "힌트 없이 계속하기" (X와 같은 동작)
- 정렬: 모바일 가운데, PC 오른쪽(위 두 버튼 끝에 맞춤)
- 위 버튼과 간격 8px

## 5. 간격·줄바꿈·폭

- 버튼 위 간격 +8px (`pt-2`)
- 설명은 단어 단위 줄바꿈 (`break-keep`). 두 창 공통
- 양옆 16px 여백, 둥근 모서리, 최대 폭 `max-w-md` (첫 방문 안내 창과 같게)

## 6. 초성 힌트 성공 토스트 없음

- 초성 힌트는 목록의 초성 줄과 날짜 제목으로 확인되므로 성공 토스트는 없다. 실패 안내는 `input/plan.md` 3 (excel은 토스트, D-3)
- `useGameState`라 excel도 같이 빠짐

## 7. 모바일 정렬·줄바꿈 (360px·375px)

- 제목·설명은 왼쪽 정렬 (`text-left`, 두 창 공통)
- 첫 번째 창 제목은 모바일에서만 "포기하기 전에" 뒤에서 줄바꿈
- 설명은 360px에서 두 줄에 들어가게 짧게 (스펙 C-2 예시도 같이)
