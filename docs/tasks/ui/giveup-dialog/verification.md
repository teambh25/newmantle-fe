# 포기 확인 창: 검증

공통 원칙·레벨·mock 정책은 `../README.md`.

동작(각 선택지를 누른 결과, 처음 포커스)은 힌트·포기 작업의 B-2·C-2 테스트로 확인. 4로 첫 번째 창의 선택지가 늘어 아래 두 개를 고침. 선택지는 이름의 일부(/초성/, /포기/, /계속/)로 찾아서 이름이 바뀌어도 그대로 동작. 색·위치·제목 문구·간격은 화면 테스트로 확인하지 않는다. 성공 토스트를 확인하던 테스트는 없음.
