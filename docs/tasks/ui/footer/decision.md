# 푸터: 결정 기록 (2026-11-12)

- 원작 소개를 본문 → 푸터: 본문 가운데 하단은 위치가 애매하고 글씨가 컸음 (문구 두 줄 + 꼬맨틀 링크 버튼)
- "개선된 버전"은 원작을 낮추는 느낌이라 "영감을 받아"만 남김. "~입니다"는 푸터만 딱딱해 보여 해요체로
- `© 2026 뉴맨틀. All rights reserved.` 삭제: 저작권은 표시 없이도 생기고 "All rights reserved"는 법적 의미가 거의 없음
- 왼쪽 "뉴맨틀" 제목 삭제: 로고는 헤더에 있고, 모바일에서는 링크 줄 위로 쌓여 어색했음
- 출처 위 구분선(`Separator`) 삭제: 아래에 작은 한 줄뿐이라 선이 과함
- 내용 폭 `container`(최대 1536px) → `max-w-2xl mx-auto`: 넓은 화면에서 제목은 왼쪽 끝, 링크는 오른쪽 끝에 붙어 게임 영역과 줄이 안 맞았음
