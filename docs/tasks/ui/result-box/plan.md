# 결과 상자 (classic)

게임이 끝났을 때(정답 맞힘·포기) 입력창 위에 뜨는 결과 상자. 내력은 `decision.md`.

1. 상자 색: 정답을 맞히면 초록, 포기하면 회색. 초록은 정답을 맞혔을 때만. 맞힘·포기 구분은 상자 색이 맡고, 날짜 제목의 정답 타일은 둘 다 파랑 (`word-list/plan.md` 4)
2. 공유 버튼을 결과 상자 안에 둔다 (이름 "공유하기")
3. 피드백 보내기 버튼을 결과 상자 안에 둔다. 설정 메뉴의 "피드백 남기기"와 같은 창을 연다
4. 정답 좋았다/별로였다 투표는 없다. 의견은 3의 피드백으로 받는다
5. 로그인 안내: **비로그인만**, 결과 문구 아래 한 줄 문구. 로그인 링크는 없다 (헤더에 로그인 버튼이 바로 있음). 로그인 유저에게는 없음
   - 사실 확인: 로그인하면 게스트 기록이 계정으로 연결됨 (`useGuestLink` → `POST /v2/stats/link`)
   - 헤더 로그인 말풍선은 한 번만 뜨고, 로그인 안내는 이 상자가 매번 한다 (`header/plan.md` 5)
6. 정답을 맞혔을 때 토스트는 띄우지 않는다. 축하 멘트(몇 번째 시도에 맞혔는지 포함)는 결과 상자에. 꽃가루는 그대로
7. 공유·피드백 버튼은 같은 모양 (같은 흰 바탕 테두리 버튼 + 같은 계열 선 아이콘). 버튼 테두리·글씨는 상자 색을 따른다: 정답은 초록, 포기는 회색

## 코드

- `src/components/classic/NewMantleForm/GameResult.tsx`: 상자 색, 공유·피드백, 로그인 안내 (1 ~ 5, 7)
- `src/hooks/useGameState.ts`: 정답 토스트 제거 (6)
