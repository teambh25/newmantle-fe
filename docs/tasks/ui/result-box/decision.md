# 결과 상자: 결정 기록

## 로그인 안내 (2026-11-13)

- 헤더 로그인 말풍선을 5초 뒤 닫히게 하면서(`header/decision.md`), 로그인 안내를 게임이 끝난 결과 상자에서 한 번 더 하기로
- 처음: 결과 문구 아래 한 줄 + 로그인 링크(`/login`)
- 링크는 빼고 문구만 남김: 헤더에 로그인 버튼이 바로 있음

## 상자 정리 (2026-11-13)

- 포기도 초록이던 상자 → 회색. 초록은 정답 전용 (색 원칙, `word-list/plan.md`)
- 공유 버튼: 상자 밖 "도전장 보내기" + 위 "친구는 나보다 빨리 맞힐까요?" 문구 → 상자 안 "공유하기", 문구는 뺌
- 정답 투표(좋았다/별로였다) → 뺌. 의견은 피드백 버튼으로
- 정답 토스트 → 뺌. 축하 멘트는 결과 상자로
- 공유·피드백 버튼 모양을 맞춤: 흰 바탕 테두리 버튼 + 선 아이콘, 색은 상자 색
- 날짜 제목의 정답 타일이 상자와 같은 초록·회색이라 겹쳐 보여서 타일은 파랑으로 (`word-list/decision.md`)

## 결과 상자 → 결과창 모달 (2026-11-13 ~ 14)

입력창 위 결과 상자를 결과 모달로 바꿨다. 지금 규칙은 `plan.md`, 화면 확인 내력은 `verification.md` 결과 기록.

- 자동 표시: 정답·포기 그 순간에만. "보여줬는지"를 저장하지 않아 새로고침하면 다시 뜨지 않는다. 꽃가루와 제목의 정답이 먼저 보이게 0.7초 늦춰 연다
- 늦추는 동안 단어를 더 내지 않게, 자동으로 연 결과창을 닫을 때까지 입력창을 잠금 (화면 확인 중 추가)
- 색: 상자의 초록 → 흰 배경 + 파랑 포인트. 포기는 회색. 축하에 이모지
- 로그인 안내: 상자 안 문구(위 "로그인 안내") → 결과창 안에서는 뺌. 대신 결과창이 열린 동안 헤더 로그인 버튼을 어두운 배경 위로 강조하고 말풍선 (`plan.md` 8)
  - 결과창이 열린 채 로그인 버튼을 누르면 결과창이 먼저 닫히고 닫히는 동안 남은 배경이 클릭을 가로채 PC에서 이동하지 않던 문제 → 강조된 로그인 버튼 누름은 바깥 클릭으로 보지 않음
- 계속 플레이: 큰 버튼 → 배너 → 작은 글자 버튼으로 여러 번 바꿈. "한 번 더 플레이"로 읽히지 않게(하루 한 번 게임) 순위권 단어를 더 찾는다는 문구로. 다음 퀴즈 시각 안내를 바로 위에 두고 문구가 "그때까지"로 이어 받음
- 메인 완료 표시: 배너 → 배경 없는 한 줄 "요약 · 결과창 보기 ›"
- 피드백: 결과창을 닫고 피드백 창을 연다(모달을 겹치지 않음). 처음엔 피드백 창을 닫으면 게임 화면으로 갔으나, 피드백 작업에서 결과창으로 돌아가게 바꿈 (`../feedback/decision.md` Dec-18)

## 알려진 위험 (보류)

- 0.7초 자동 열기 타이머를 수동 열기·닫기 때 정리하지 않는다. 정답 직후 0.7초 안에 "결과창 보기"로 열었다 닫으면 타이머가 결과창을 한 번 더 연다(이번엔 입력 잠금 없음). 같은 사이에 설정 → 피드백을 열면 결과창이 그 위에 겹친다. 0.7초 안에 일부러 눌러야 생기고, 생겨도 닫으면 끝이라 보류 (2026-11-16 머지 전 리뷰). 고친다면 수동 열기·닫기에서 타이머를 `clearTimeout`
