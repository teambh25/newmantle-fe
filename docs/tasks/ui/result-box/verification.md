| R-1-2 | 화면 | 메인, 오늘 포기함 | 진입 | 결과 상자 안에 공유하기 버튼과 피드백 버튼이 있음 |
| R-1-3 | 화면 | 메인, 오늘 정답 맞힘 | 결과 상자의 피드백 버튼 클릭 | 피드백 창(dialog)이 열림 |
| R-2-1 | 화면 | 메인, 오늘 정답 맞힘 | 진입 | 정답 투표 버튼(좋았다 / 별로였다)이 없음 |
