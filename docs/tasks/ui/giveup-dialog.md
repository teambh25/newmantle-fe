# 계획: 포기 확인 창 정리 (classic)

색 정리(`color.md`) 중에 나온 포기 확인 창 고민. 스펙: `docs/spec/hint-giveup.md` B-2, C-2

- 범위: classic. excel은 그대로 (`docs/todo/excel.md`)

## 1. 포기 버튼 색

- 이 창의 목적은 경고보다 계속 플레이로 유도. 파랑·빨강 둘 다 꽉 찬 버튼이라 시선이 나뉘고, 빨강이 오히려 눈에 띔
- 포기 버튼 빨강(`destructive`) → 회색 테두리(`outline`). 계속 플레이 쪽만 꽉 찬 파랑
- 되돌릴 수 없다는 경고는 제목·설명이 맡는다

## 2. 버튼 위치

- 증상: 모바일에서 버튼이 코드 순서와 반대로 쌓여 포기가 맨 위에 옴
- 원인: 공통 `DialogFooter`가 `flex-col-reverse sm:flex-row` ("주요 버튼을 마지막에 둔다"는 가정)
- 계속 플레이 쪽을 코드상 마지막에 → PC 오른쪽, 모바일 위 (웹에서 흔한 배치)
- 두 창(초성 미사용 / 사용 후) 모두 계속 플레이 쪽이 같은 자리. 같은 자리를 눌렀는데 한 창에선 계속, 다른 창에선 포기가 되면 안 됨

## 3. 첫 번째 창(초성 미사용) 질문 바꾸기

- 문제: 제목이 "정말 포기하시겠습니까?"라 "예" = 포기 → "진행은 오른쪽" 관례로는 포기가 오른쪽이어야 할 것 같음. 그런데 유도하고 싶은 건 초성 힌트
- 제목을 초성 힌트를 권하는 질문으로 바꿔서 초성 힌트가 "진행"이 되게 한다
  - 제목: "포기하기 전에 초성 힌트를 받아볼까요?"
  - 선택지: "초성 힌트 받기"(강조, 오른쪽·위) / "포기하고 정답 보기"(덜 강조). 무슨 일이 생기는지 버튼 이름에 드러나게
- 두 번째 창(초성 사용 후)은 진짜 포기 확인이라 그대로: "정말 포기하시겠습니까?", "계속 도전하기" / "포기하기"
- 유도는 하되 포기 버튼은 잘 보이고 이름이 분명해야 한다. 죄책감을 주는 문구(confirmshaming)는 쓰지 않는다

## 4. 초성 없이 계속하기

- 문제: 첫 번째 창에서 "초성 힌트 없이 계속"은 X(창 닫기)뿐이라 X를 누르면 어떻게 되는지 헷갈림
- 두 버튼 아래에 작은 회색 밑줄 글씨 버튼 "힌트 없이 계속하기" (X와 같은 동작). 첫 번째 창에만
- 정렬: 모바일 가운데, PC 오른쪽(위 두 버튼 끝에 맞춤). 처음엔 PC도 가운데라 어색했음
- 창이 한 줄만큼 커져서 위 버튼과 간격을 8px로 줄임

## 5. 간격·줄바꿈·폭

- 설명(회색 글씨)과 버튼이 붙어 PC에서 답답함 → 버튼 위 간격 +8px (`pt-2`)
- 모바일에서 설명이 단어 중간에서 줄바꿈 (한국어 기본 줄바꿈) → `break-keep`으로 단어 단위. 두 창 공통
- 창이 모바일에서 화면 끝까지 붙음 → 첫 방문 안내 창처럼 양옆 16px 여백, 둥근 모서리, 최대 폭 `max-w-md`

## 6. 초성 힌트 성공 토스트 제거

- 토스트 위치가 모바일은 화면 위라 게임을 가림 (공통 설정이라 위치는 그대로)
- 초성 힌트는 목록의 초성 행으로 확인되므로 성공 토스트는 뺀다. 실패 토스트(D-3)는 유지
- `useGameState`라 excel도 같이 빠짐
- 초성 힌트 위치 변경은 아직 고민 중 (별도)

## 7. 모바일 정렬·줄바꿈 (360px·375px)

- 제목·설명이 모바일에서 가운데 정렬: 공통 `DialogHeader`가 `text-center sm:text-left` → 이 창은 `text-left`로 고정 (두 창 공통)
- 첫 번째 창 제목이 모바일에서 애매한 곳에서 줄바꿈 → 모바일에서만 "포기하기 전에" 뒤에서 줄바꿈
- 설명: 쉼표 뒤 줄바꿈만으로는 360px에서 뒷부분이 다시 두 줄이 돼서 뒷부분을 줄임
  - "포기하면 정답이 공개되고, / 이후 입력한 단어는 기록되지 않아요." (스펙 C-2 예시도 같이 수정)

## 테스트

동작(각 선택지를 누른 결과, 처음 포커스)은 기존 B-2·C-2 테스트로 확인. 4장으로 첫 번째 창의 선택지가 늘어 아래 두 개를 고침. 선택지는 이름의 일부(/초성/, /포기/, /계속/)로 찾아서 이름이 바뀌어도 그대로 동작. 색·위치·제목 문구·간격은 화면 테스트로 확인하지 않는다 (문구는 검증하지 않는 원칙). 성공 토스트를 확인하던 테스트는 없음

| ID | 전제 | 동작 | 기대 |
| --- | --- | --- | --- |
| B-2-1 (변경) | 초성 미사용 | 포기 버튼 | 선택지 3개 (초성 힌트 / 포기 / 힌트 없이 계속), 요청 없음 |
| B-2-4 (신규) | 초성 미사용 | 힌트 없이 계속 | 요청 없음, 창 닫힘, 다시 열면 초성 선택지 그대로 |
