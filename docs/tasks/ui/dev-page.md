# 개발용 화면 확인 페이지 (`/dev`)

개발 서버에서 화면 상태를 바로 만들어 보는 페이지. 기존 `/dev/word-list`(`word-list.md` 5장)를 합쳐 넓힌다. (2026-11-13)

## 요구사항

1. 한 페이지(`/dev`)에서 가짜 단어 목록 설정과 실패 화면 설정을 함께 한다. `/dev/word-list`는 없앤다
2. 가짜 단어 목록: 기존 시나리오 그대로. 누르면 오늘 기록을 덮어쓰고 메인으로. `?s=<시나리오>`로 바로 적용 (헤드리스 캡처용)
3. 예외 상황: 실패했을 때 화면을 보기 위한 버튼 4개. 누르면 그 요청이 **다음 한 번** 실패하도록 해 두고 메인으로
   - 단어 제출 실패 / 힌트 실패 / 초성 힌트 실패 / 포기 실패
   - 실패 종류(500, 시간 초과 등)는 고르지 않음: 화면은 "없는 단어(404)"와 "그 밖의 실패" 두 갈래뿐이고, 갈래는 테스트(Y-2-1, Y-3-1)가 확인. 없는 단어는 직접 입력해 보면 됨
   - 한 번 실패하면 꺼짐 ("계속" 선택지 없음: 화면을 보는 데는 한 번이면 충분)
   - 힌트·초성 힌트·포기 실패는 기록을 비우고 시작 (가짜 목록에 20위 안 단어가 있으면 힌트 버튼이 꺼져 있어서)
4. 개발 서버의 모든 화면 왼쪽 아래에 DEV 표시를 두고 눌러서 `/dev`로 돌아간다. 실패가 대기 중이면 무엇인지도 보여주고 바로 취소할 수 있다
5. 개발 서버에서만 동작. 배포 빌드에는 페이지도, 응답을 바꾸는 코드도 들어가지 않는다
6. 메인 게임 코드는 건드리지 않는다. 진짜 서버 대신 브라우저에서 응답만 바꾼다
