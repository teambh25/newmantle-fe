# 검증: 모바일 UI 정리

## 원칙

- 기준: `plan.md`의 결정 사항. 구현을 보고 케이스를 만들거나 바꾸지 않는다
- 요소는 role과 접근 가능한 이름으로 찾는다. 문구는 검증하지 않는다
- 테스트 이름 앞에 케이스 ID를 붙인다
- 레이아웃·글씨 크기는 jsdom에서 확인할 수 없어 수동으로 본다

## 검증 레벨

| 레벨 | 도구 | 대상 |
| --- | --- | --- |
| **화면** | vitest + React Testing Library + user-event | 로그아웃 버튼 위치, 로그아웃 요청 |
| **수동** | 브라우저 (iPhone SE 등 좁은 기기 + 실제 폰) | 헤더 한 줄, 닉네임 말줄임, 공지 글씨 |

## mock 정책

`src/test/README.md`와 같다. Supabase는 가짜 클라이언트 (기본 비로그인, `L-*`는 로그인 세션). `signOut`은 spy로 호출만 확인한다.

## T. 통계 유도 말풍선

사전 상태: 첫 방문 안내 모달을 본 상태(`newmantle_rule_modal_seen`)가 기본. 말풍선은 닫기 버튼(접근 가능한 이름 "통계 안내 닫기")으로 찾는다.

| ID | 레벨 | 사전 상태 | 행동 | 기대 결과 |
| --- | --- | --- | --- | --- |
| T-1-1 | 화면 | 메인, 로그인 | 메인 진입 | 통계 말풍선이 보임, 로그인 말풍선은 없음 |
| T-1-2 | 화면 | 메인, 비로그인 | 메인 진입 | 통계 말풍선이 없음 (로그인 말풍선은 보임) |
| T-1-3 | 화면 | 메인, 로그인 | X로 닫기 → 다시 렌더링 | 닫히고 `stats-tooltip-dismissed`가 저장됨, 다시 열어도 없음 |
| T-1-4 | 화면 | 메인, 로그인, 첫 방문 (모달 안 봄) | 메인 진입 → 모달 닫기 | 모달이 열려 있는 동안 통계 말풍선이 없고, 닫은 뒤 보임 |
| T-2-1 | 화면 | `/stats`, 로그인 | 통계 페이지 진입 | `stats-tooltip-dismissed`가 저장됨 |
