## R. 결과창 모달 (`result-box.md`)

기준은 `result-box.md` 요구사항 (2026-11-13 결과 상자 → 결과창 모달). 사전 상태는 H와 같음 (첫 방문 모달 봄). "정답 맞힘 / 포기 저장"은 오늘 날짜 기록을 `localStorage`에 넣고 진입한 것 (= 새로고침 후).

찾는 방법 (문구는 보지 않는다. 이름을 바꾸면 여기와 테스트를 같이 고친다)
- 결과창: 이름 "게임 결과"인 대화상자(dialog). 첫 방문 모달·피드백 창도 dialog라 이름으로 구분
- 메인 완료 표시: 이름에 "결과창 보기"가 들어간 버튼 (이름 앞에 결과 요약이 붙음). 표의 "결과 다시 보기"는 이 버튼을 누르는 것
- 헤더 로그인 강조: 헤더 `/login` 링크에 접근 가능한 설명(말풍선)이 붙어 있는지. 결과창이 열리면 바깥이 aria-hidden이라 hidden 포함으로 찾는다
- 모달 안: "공유하기" / "피드백" 버튼, 계속 플레이(닫기) 버튼은 이름에 "순위권 단어"가 들어간 버튼, 닫기는 이름 "Close"(Radix 기본 X)
- 정답 정보: 가짜 서버 `ANSWER`의 `word` / `tag` / `description`이 결과창 안에 보이는지 (서버 데이터라 문구 검증이 아님)

이전 결과 상자 케이스 R-1-1 ~ R-1-3(입력창 위 "게임 결과" 영역)은 모달로 바뀌어 아래 R-1 ~ R-5로 대체한다. R-2-1·R-3-1은 규칙이 그대로라 사전 상태만 맞춰 유지한다.
