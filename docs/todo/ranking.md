# 랭킹 (향후 계획)

몇 번째 시도에 맞췄는지로 유저별 랭킹을 만들 계획. 아직 구체화 전이라 논의된 내용만 기록.

## 필요 사항

- **힌트 사용 횟수에 따른 랭킹 가중치 적용 필요**
  - 시도 횟수만 보면 힌트를 많이 쓸수록 유리해짐
  - 후보: 힌트 미사용자 별도 랭킹 / 힌트 1개를 시도 n회로 환산 / 힌트 수 → 시도 횟수 순 정렬 / 초성 힌트·포기 기록 제외

## 관련 결정 사항

- 힌트 순위는 유저마다 다름 (최고 순위 × 0.75, `docs/spec/hint-giveup.md` A-5). 힌트 1회의 효과가 비율로 같으므로 공정성은 힌트 순위가 아닌 랭킹 가중치로 맞춘다
- 랭킹 기준을 정할 때 같이 볼 `docs/spec/hint-giveup.md` 항목
  - B-4: 초성 힌트를 힌트 사용 횟수에 포함하는지
  - C-4: 포기 시 기록할 시도 횟수
  - D-2: 힌트 연속 클릭 시 중복 요청 → 서버 통계(힌트 횟수) 중복 기록. 랭킹 도입 전 수정 필요
- 게임 종료 후 1000위 이내 단어 공개 예정 (공개 시점은 게임 종료 후로 한정)
