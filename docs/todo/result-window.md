# 결과창 축하감 보강 (향후 개편)

결과창(`docs/tasks/ui/result-box/plan.md`)이 이전 입력창 위 결과 상자보다 심심하다는 피드백이 있었다. 원인과 개선 방향을 기록한다. 세부 디자인은 화면을 보며 정한다.

## 현재 상태와 원인

이전 결과 상자와 비교하면 다음이 바뀌었다 (`git show bb289b1`, `fa5e0b9`, `fddd13e`).

| 항목 | 이전 (입력창 위 상자) | 지금 (결과창 모달) |
| --- | --- | --- |
| 바탕·테두리 | 초록 배경과 초록 테두리 | 흰 배경, 파랑 포인트 |
| 포기 | 상자 색 변화 | 회색 |
| 축하 | 색과 굵은 문장 | 이모지 한 개 |
| 정답 단어 | 상자 안에서 같이 보임 | 연한 회색 블록, 작은 글씨 (날짜 제목과 중복이라 강조 안 함) |
| 안내 문구 | 다음 날 도전 안내, "도전장" 문구 | 다음 퀴즈 시각(작은 회색 글씨)만 |
| 정답 투표 | 있음 | 없음 (피드백으로 이동) |
| 계속 플레이 | (해당 없음) | 작은 밑줄 글자 버튼 |

원인은 의도한 결정이다. 이 방향이 축하감을 줄였다.

- 초록은 "정답 전용" 색 원칙에서 뺐다 (`result-box/decision.md`, 2026-11-13). 대신 흰 배경과 파랑으로 바꿨다. 색이 약해져서 상자가 옅어 보인다.
- 정답 단어를 날짜 제목과 겹치지 않게 강조하지 않는다.
- 계속 플레이를 "한 번 더 플레이"로 읽히지 않게 줄였다 (하루 한 번 게임).
- 결과창은 배경을 어둡게 한 모달이라, 게임 화면에서 떨어져 나온 확인 창처럼 보인다.

## 개선 후보

- **맞힘과 포기의 구분을 살린다**: 맞혔을 때만 파랑 채움 헤더 띠를 두거나, 시도 횟수를 크게 보여준다. 포기는 회색 유지.
- **축하 연출**: 이모지 대신 아이콘이나 짧은 애니메이션. 꽃가루는 이미 있으므로 결과창 등장과 맞춘다.
- **정답 블록 복원 여부**: 흰 카드로 올려 시각적 무게를 주거나, 지금처럼 작게 둔다. 날짜 제목과 중복이므로 정답 대신 카테고리(`tag`)를 크게 보여주는 것도 방법.
- **시도 횟수 표현**: 숫자를 크게 보여주는 구성. 현재 문장형은 유지할지 정한다.
- **색 원칙 재검토**: 결과창에 한해 초록 또는 다른 축하 색을 허용할지. 초록을 다시 쓰면 `result-box/decision.md`의 2026-11-13 결정을 뒤집는 것이므로 함께 결정한다.

## 정해야 할 것

- 색 원칙: 결과창 축하 색을 허용할지 (`docs/tasks/ui/word-list/plan.md` 색 원칙과 함께 확인)
- 정답 블록 강조 정도 (날짜 제목과의 역할 분담)
- 맞힘과 포기의 시각 차이 크기
- 계속 플레이 버튼의 존재감 (하루 한 번 게임이라는 안내와 충돌하지 않게)
- excel 테마 결과 블록과 맞출지 여부 (`docs/specs/excel-ui/decisions.md`)
