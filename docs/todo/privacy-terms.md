### 2-2. 동의 절차

- Google OAuth 동의 화면은 "Google이 이 앱에 정보를 넘겨도 되는지"에 대한 동의라서, 서비스의 수집·이용 동의를 대신하지 않음
- 회원 서비스에 꼭 필요한 정보는 계약 이행 근거로 동의 없이 처리 가능(제15조 제1항 제4호). 국외 이전도 계약 이행에 필요한 처리위탁·보관이면 처리방침 공개로 갈음 가능(제28조의8 제1항 제3호)
- → 체크박스 없이 처리방침 공개 + 로그인 화면에 "로그인하면 개인정보처리방침을 확인한 것으로 봅니다" + 링크
- 기존 가입자: 처리방침 공개 + 공지로 안내
- 법률 검토는 아님. 공개 전 확인 권장

### 2-3. 같이 볼 것

- `sharer_id`가 user id 그대로 노출: 처리방침에 기재하고, 공유 방식 변경은 `docs/todo/share.md`에서
- 피드백: Make.com 웹훅 URL이 클라이언트에 노출(아무나 요청 가능), 본문이 Amplitude에도 중복 전송. Amplitude 쪽 본문 제거 검토
