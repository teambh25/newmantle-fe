# 공유 (향후 개편 예정)

대대적인 개편 예정이라 현재 파악된 내용만 기록.

## 현재 확인된 문제

- 포기한 유저도 "도전장 보내기"로 공유 가능하지만, 공유 링크(`shared_attempts`)에 포기 여부가 없음 → 친구에게는 "N번 만에 맞힘"처럼 보일 수 있음
- 포기 시 공유 링크의 시도 횟수가 결과 창보다 1 많음 (N+1) → `docs/spec/hint-giveup.md` C-4에서 N으로 통일하기로 결정
- 친구 비교 바의 "친구 힌트 n회 사용"은 서버 `hint_count` 기준 (`docs/spec/hint-giveup.md` B-4)
