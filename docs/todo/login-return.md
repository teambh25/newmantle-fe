# 로그인 후 원래 페이지로 돌아가기 (할 일)

## 문제
- 어디서 로그인하든 로그인이 끝나면 항상 메인(`/`)으로 간다
  - 통계 페이지에서 로그인 → 메인으로 감. 통계 페이지로 돌아와야 자연스럽다
  - classic 결과창이 열린 채 로그인 → 메인으로 오고 결과창은 닫혀 있음 (다시 열기 띠만 보임)

## 원인
| 단계 | 위치 | 지금 |
| --- | --- | --- |
| 헤더 로그인 링크 | `src/components/AuthButton.tsx` | `/login`으로만 감. 원래 경로를 넘기지 않음 |
| Google 로그인 시작 | `src/app/login/page.tsx` | 돌아올 주소가 `/auth/callback`으로 고정 |
| 로그인 완료 | `src/app/auth/callback/route.ts` | 무조건 `/`로 보냄 |
| 게스트 기록 연결 | `src/hooks/useGuestLink.ts` | 메인(`src/app/page.tsx`)에서만 실행 |

## 할 것
1. 돌아올 경로를 로그인 끝까지 넘긴다
   - 로그인 링크에 현재 경로를 붙이고(`/login?next=...`), callback이 그 경로로 보낸다
   - 전달 방법: 쿠키에 잠깐 저장했다가 callback에서 꺼내는 쪽을 우선 검토. OAuth 돌아올 주소에 쿼리를 붙이면 Supabase 허용 주소(Redirect URLs)와 맞지 않아 기본 주소로 튈 수 있음 (대시보드 설정 확인 필요)
   - 사이트 안쪽 경로(`/`로 시작, `//` 아님)만 받는다. 밖으로 보내는 데 악용되지 않게 (open redirect)
2. 게스트 기록 연결을 모든 페이지에서 실행한다
   - `useGuestLink`를 메인에서 빼서 layout 쪽(`AmplitudeInitializer`처럼 모든 페이지에 깔리는 곳)으로
   - 연결은 비동기이고 실패하면 다시 시도한다. 통계 페이지가 연결 전에 통계를 불러오면 게스트 기록이 빠진 숫자가 보이므로, 연결이 끝나면 통계를 다시 불러와야 한다

## 하지 않기로 한 것 (일단)
- classic 결과창에서 로그인했을 때 돌아와서 결과창 다시 열기. 어렵진 않지만(로그인 전에 표시 저장 → 메인에서 게임이 끝난 상태면 열기) 다시 열기 띠가 있어서 보류. excel은 결과가 시트에 늘 보여서 해당 없음
