# 첫 단어 입력 유도 (계획)

메인에 들어와서 단어를 하나도 입력하지 않고 나가는 유저가 많은 것 같다 (체감, 수치 확인 필요). 첫 단어를 넣게 만드는 방법을 정리한다.

## 1. 지금 한 것

- 입력창 placeholder: 아직 입력한 단어가 없으면 "아무 단어나 입력해보세요", 한 번이라도 입력했으면 "단어 입력", 에러가 나면 에러 문구 (`src/components/classic/NewMantleForm/GameForm.tsx`, classic만)
- 첫 방문 모달은 `docs/spec/rules.md` 2장 (아직 구현 전)

## 2. 먼저 측정

Amplitude에 이미 있는 이벤트로 볼 수 있다.

| 이벤트 | 언제 | 비고 |
| --- | --- | --- |
| `Game Started` | 메인 진입 (날짜가 정해진 뒤 매번) | 재방문·이미 끝낸 게임에서도 발생 → 이벤트 수 기준이면 비율이 낮게 나옴 |
| `Word Submitted` (`attempt: 1`) | 첫 단어 제출 | 힌트로 받은 단어는 포함 안 됨 |

- 지표: 오늘 `Game Started`한 **유니크 유저** 중 `Word Submitted` 한 유저 비율 (Amplitude Funnel, 같은 날)
- 신규 유저만 따로 보기 (첫 방문 유저가 핵심 대상)
- placeholder 배포 전후, 모달 배포 전후로 비교 → 배포일 기록

## 3. 추가 후보 (수치를 보고 결정)

- [ ] 입력창 말풍선 "아무 단어나 입력해보세요": 첫 방문 모달·로그인 말풍선과 겹침 (`rules.md` M-6), 모바일 키보드에 가려질 수 있음
- [ ] 입력창 자동 포커스: 모바일에서는 키보드가 바로 올라와 화면을 가림 → 데스크톱만 검토
- [ ] 예시 단어 버튼 (예: "사랑", "학교"를 누르면 바로 제출): 아무거나 넣어도 된다는 걸 보여줌. 시도 횟수에 들어가는 점 안내 필요
- [ ] 공유 링크로 들어온 유저: 비교 바가 있어 동기가 다를 수 있음 → 따로 측정
- [ ] excel 테마 적용 여부
