# Top 1000 단어 공개 (향후 계획)

오늘 퀴즈에서 정답과 유사도가 높은 단어 1000개(1~999위 + 정답)를 공개하는 기능. 결과창(`docs/tasks/ui/result-box.md`)에서 들어간다.
아직 정책이 정해지지 않은 먼 계획이라, 논의된 방향과 결정할 것만 기록한다.

## 논의된 방향

- 정답을 맞힌 사람만 결과창에서 볼 수 있게 한다
- 목록을 보면 그날은 더 제출할 수 없게 한다 (보기 전 확인 단계 필요. 되돌릴 수 없는 행동)
- 공유는 원하지 않는다. 주소로 바로 들어오거나 공유되는 것을 줄이는 쪽으로 만든다
- 나중에 "Top 1000 단어 중 몇 개를 맞혔는지" 점수를 넣을 수도 있다 (미정)
- 단어별 만족 / 불만족을 조사하면 나중에 평가 데이터로 쓰기 좋음

## UI 후보

- 목록이 길어 결과 카드 안에 바로 넣기는 어렵다
- **결과 모달 안에서 화면 전환 (유력)**: 결과 화면 → 확인 단계 → 목록 화면, 뒤로가기로 결과 화면 복귀. 모달을 겹치지 않고, 들어가는 길이 결과창 하나뿐이라 열람 시점(= 제출 종료)을 정하기 쉽다
- 별도 페이지: 주소가 생겨 공유·직접 접근을 막기 어렵고 열람 처리 시점이 애매해서 정책과 잘 맞지 않음
- 메인 입력 기록 영역: 내 기록이 아니라 오늘 퀴즈의 단어 목록이라 맞지 않음

## 결정할 것

- 정답을 맞힌 뒤에도 제출을 계속 받을지 (점수를 넣는다면 필요). 지금 정답 후 입력 동작과 같이 정해야 함
- 포기한 사람도 볼 수 있는지
- 열람 후 제출 잠금을 서버에서도 막을지. 프론트만 막으면 localStorage 삭제나 다른 기기로 우회된다. 정답 전 목록 요청도 서버가 거부해야 함
- 열람 여부를 새로고침 후에도 유지 (결과창의 자동 표시 여부 / 게임 완료 여부와 별도 상태)
- 목록 API 형태 (현재 `hint/{rank}`는 한 단어씩)
