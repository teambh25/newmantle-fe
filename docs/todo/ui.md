# UI 정리 (나중에 한 번에)

모바일 기준으로 어색한 UI를 모아뒀다가 한 번에 손본다. 이번 범위는 classic 테마.

## 1. 헤더가 한 줄에 안 들어감

- 증상: 모바일(약 375px)에서 왼쪽 "뉴맨틀 / 단어 추측 게임"이 잘리거나 줄바꿈됨
- 원인
  - 로그인하면 오른쪽에 "닉네임님" + 로그아웃 버튼이 생겨 로그인 버튼보다 훨씬 넓어짐 (닉네임 길이에 따라 더 길어짐). 규칙 작업 전부터 있던 문제
  - 규칙 작업에서 헤더에 `?`(규칙) 버튼 추가 (`docs/tasks/rule/plan.md` 3장)
- 대략 폭 (375px 화면, 좌우 여백 제외 약 343px)
  - 왼쪽 로고 + 부제: 약 180px
  - 오른쪽 (비로그인): 로그인 + `?` + 통계 + 설정 + 간격 ≈ 204px → 합계 약 384px로 넘침
- 코드: `src/app/page.tsx` (classic 헤더), `src/components/AuthButton.tsx`
- 후보
  - A. 작은 화면에서만: 부제 "단어 추측 게임" 숨김, 아이콘 간격 16px → 8px, 로고 줄바꿈 방지, 로그인 시 닉네임 숨기고 로그아웃만
  - B. 로그아웃을 설정 메뉴로 옮기고 헤더에는 닉네임만 (길면 말줄임). 회원 탈퇴 진입점도 설정 메뉴로 추천돼 있어 계정 기능이 한 곳에 모임 → 탈퇴 작업과 같이
- `/stats` 헤더도 같은 `AuthButton`을 써서 같이 확인

## 2. 공지사항 글씨가 너무 큼

- 증상: 메인 공지사항의 제목·본문 글씨가 게임 영역에 비해 큼
- 코드: `src/components/classic/NotificationFeed.tsx`
  - 영역 제목 `text-xl`, 공지 제목 `text-lg`, 본문 기본 크기(`text-base`, 16px), 날짜 `text-sm`
- 후보: 공지 제목 `text-base`, 본문 `text-sm` 정도로 한 단계씩 낮추기. 공지 페이지 분리 계획(`docs/todo/notices.md`)과 같이 볼 것

## 확인 방법

- 크롬 개발자 도구 기기 툴바(iPhone SE 등 좁은 기기) + 실제 폰
