# 수동 확인

자동 테스트로 보지 않는 것(모양, 배치, 색, 타이밍, 실제 폰 동작)을 화면에서 직접 확인하는 목록. 기능별 `verification.md`의 "수동 확인"과 `docs/tasks/ui/phone-checks.md`를 한 곳에 모았다 (2026-11-16, `verification.md`는 그 뒤 삭제).

- ID는 원래 문서의 ID를 그대로 쓴다. 기능마다 V 번호가 겹치므로 "기능 + ID"로 부른다 (예: 헤더 V-8)
- 대체·취소된 항목(단어 목록 V-12·V-27·V-28, 결과창 V-18)은 뺐다
- 상태: 통과(날짜) / 대기 / 재확인 대기
