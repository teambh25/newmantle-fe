# 게임 규칙 (유저 안내용)

유저에게 보여주는 게임 규칙. `/rule` 페이지와 첫 방문 안내 모달의 내용 기준이다.

- 내부 규칙의 기준 문서는 `docs/spec/hint-giveup.md`. 이 문서는 **유저용 요약**이며, 내부 스펙이 바뀌면 같이 고친다
- 페이지·모달 구현 계획은 `docs/tasks/rule/`

## 원칙

- 유저 입장에서 간단히 쓴다. 내부 계산 방식은 쓰지 않는다 (예: 힌트 비율 `HINT_RATIO` 0.75는 비공개)
- **초성 힌트는 쓰지 않는다.** 포기하려는 유저에게 포기 확인 창에서 깜짝 선택지로 주는 장치(`hint-giveup.md` B)라서, 미리 알리면 효과가 줄어든다
- 수치는 코드 상수에서 가져온다: `HINT_LIMIT_RANK`(20) 등 `src/utils/gameRules.ts`
- 형식: 질문형 소제목(예: "어떻게 플레이해요?") + 짧은 답을 나열. 접고 펴는 아코디언이 아니라 모두 펼쳐 둔다
- 순위(R-2)와 힌트(R-4)는 한 질문으로 묶는다
- UI는 오늘 문제만 플레이 가능 (API는 어제도 허용하지만 화면에 노출 안 함) → "어제 문제" 안내 불필요

## 규칙

| # | 항목 | 내용 |
| --- | --- | --- |
| R-1 | 기본 규칙 | 매일 정답 단어 1개. 단어를 입력하면 정답과의 유사도·순위를 알려줌 |
| R-1-1 | 없는 단어 | 게임 단어 목록에 없는 단어는 "없는 단어"로 표시. 시도 횟수에 들어가지 않음 (API `guess` 404 → 입력창에 "없는 단어입니다", 기록 변화 없음) |
| R-2 | 순위 | 1~999위. 1위는 정답 다음으로 가까운 단어. 1000위 밖은 "순위 밖" |
| R-3 | 정답 교체 | 매일 00시(KST) |
| R-4 | 힌트 | 지금 찾은 단어보다 더 가까운 단어를 알려줌. 20위 이내에 도달하면 더 받을 수 없음. 사용 횟수가 기록에 남음 |
| R-5 | 포기 | 정답 공개. 이후 입력은 기록되지 않음. 시도 횟수 = 포기 시점의 입력 횟수 |
| R-6 | 정답 이후 | 단어를 더 넣어볼 수 있지만 기록되지 않음 |
| R-7 | 기록 / 통계 | 로그인하지 않으면 기록은 7일 뒤 사라짐. 7일 안에 로그인하면 계정으로 옮겨짐. 로그인하면 통계(캘린더·요약)가 계속 남음 (근거: `docs/api/stats.md` 기록 보관 기간) |
| R-8 | 도전장 | 링크를 보내 친구와 시도 횟수를 비교 (간단히. 공유 방식이 바뀌면 수정, `docs/todo/share.md`) |
| R-9 | 원작 | 꼬맨틀의 개선된 버전. 답 문단 안에 원작 텍스트 링크 |

## 첫 방문 모달 요약

R-1, R-3을 짧은 문장 2줄로, 목록이 아니라 부드러운 문장으로: 입력하면 정답과 얼마나 비슷한지 알려줌 → 유사도를 참고해 정답 찾기. 정답 교체 시각(매일 밤 12시)은 보조 정보라 작은 회색 글씨로 나머지는 `/rule`로 안내.

## 넣지 않는 것

- 초성 힌트 (원칙 참고)
- 유사도 수치의 의미: 유사도 개편 후 추가
- 랭킹: 도입 시 추가 (`docs/todo/ranking.md`)
- 회원 탈퇴
