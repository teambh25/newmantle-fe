# excel 테마 UI 정리
> classic에서 바뀐 핵심 동작(결과, 진행 상황, 공지·규칙 진입)을 excel 메인 게임 화면에 시트 모양으로 자연스럽게 녹인다

## 1. Context
- 배경: classic UI가 크게 바뀌는 동안 excel은 그대로 남았다. 공지와 피드백이 별도 페이지와 창으로 빠졌고, 결과창과 진행 상황 카드가 생겼다. excel에는 아직 메인 공지 목록, FAQ, 옛 결과 행이 있다
- 외부 제약:
  - `useGameState`(제출·힌트·포기·저장)는 두 테마가 같이 쓴다. 테마별로 게임 규칙을 바꾸지 않는다
  - excel의 메인 색은 녹색(`#217346`)이다
  - 세세한 부분까지 classic을 따라가지 않는다. 핵심 몇 가지만 엑셀처럼 보이게 한다
  - 공용 훅을 추출하는 동안 classic 동작은 바뀌면 안 된다
- 기존 패턴:
  - classic 메인 게임 화면: `src/components/classic/NewMantleForm/`
  - 순수 계산: `src/utils/board.ts`(`buildBoard`, `gaugeFill`)
  - 공지 읽음: `useLastSeenNotice`, `MarkNoticesSeen`
  - 시트 행 형태의 피드백 폼: `src/components/excel/SurveyForm.tsx`

  - classic `NewMantleForm`의 로직을 공용 훅으로 추출 (공유 링크 생성·진입 포함) (Dec-2)
  - 하단 시트 탭(게임 / 규칙 / 통계) (Dec-11, Dec-27)
  - 녹색 상태 표시줄에 이용약관 / 개인정보처리방침 / 문의하기 (Dec-14)

## 6. Glossary
- **결과 블록** — 정답·포기 후 단어 목록 위 시트 상단에 나오는 결과 행. classic 결과창의 excel 버전
- **방금 입력 행** — 표 머리 바로 아래에 강조해서 보여 주는 최근 입력 한 줄. classic 진행 상황 카드의 배너에 해당한다
- **데이터 막대** — 엑셀 조건부 서식처럼 셀 안을 채우는 막대. 최고 순위를 보여 준다
- **시트 탭** — 화면 왼쪽 아래의 엑셀 시트 탭 모양 이동 링크
- **상태 표시줄** — 화면 맨 아래 녹색 바(`src/components/excel/Footer.tsx`)
